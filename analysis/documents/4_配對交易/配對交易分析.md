# 配對交易分析

## 功能概述

配對交易（Pairs Trading）是一種市場中性的統計套利策略。本頁面提供 Engle-Granger 共整合檢定、價差（Spread）分析、Z-Score 進出場訊號等完整的配對交易分析工具。

## 操作介面

### Sidebar 設定

| 設定項 | 說明 |
|--------|------|
| 股票 A | 配對中的第一支股票（通常為主動腿） |
| 股票 B | 配對中的第二支股票（通常為被動腿） |
| 回溯期間 | 6M / 1Y / 2Y / 3Y |
| Z-Score 移動視窗 | 10 ~ 60 日（預設 20） |
| 進場 Z-Score | 1.0 ~ 3.0（預設 2.0） |
| 出場 Z-Score | 0.0 ~ 1.5（預設 0.5） |

## 分析步驟

### Step 1：共整合檢定

使用 Engle-Granger 兩步法檢定兩支股票是否存在長期均衡關係。

**檢定流程**：
```
1. OLS 回歸：Y = β × X + α + ε
2. 對殘差 ε 進行 ADF 單根檢定
3. 若 ADF p-value < 0.05 → 共整合成立
```

**顯示指標**：

| 指標 | 說明 |
|------|------|
| ADF 統計量 | Augmented Dickey-Fuller 檢定統計量，越負越好 |
| p-value | 顯著性水準，< 0.05 表示共整合成立 |
| Beta (β) | 配對比例，Y 每變動 1 單位，X 變動 β 單位 |
| R² | 判定係數，越高表示兩股線性關係越強 |

**判讀**：
- p-value < 0.05 → 共整合成立，適合配對交易
- p-value > 0.05 → 不建議進行配對交易
- Beta 用於計算配對交易的避險比率

### Step 2：價差分析

**Spread 計算**：
```
Spread = Price_Y - (β × Price_X + α)
```

**圖表**：
1. **Spread 走勢圖**：包含均值線與 ±2 標準差帶
2. **Z-Score 圖**：標準化的 Spread，含進出場門檻線

**半衰期**：
- 使用 Ornstein-Uhlenbeck 過程估算 Spread 回歸均值的半衰期
- 半衰期越短 → Spread 越快回歸均值 → 策略獲利速度越快
- 理想的半衰期：5 ~ 30 天

### Step 3：配對交易訊號

**進出場規則**：
| 條件 | 訊號 | 動作 |
|------|------|------|
| Z-Score > +進場門檻 | Short Spread | 做空 Y，做多 X |
| Z-Score < -進場門檻 | Long Spread | 做多 Y，做空 X |
| Z-Score 回到 ±出場門檻 | 平倉 | 同時平倉兩腿 |

**圖表**：正規化價格比較圖（兩支股票），以垂直線標記進出場點。

## 關鍵概念

### 共整合 vs 相關性

| 概念 | 說明 |
|------|------|
| 相關性 | 短期價格變動方向一致性（可能隨時間改變） |
| 共整合 | 長期價差維持在穩定範圍（均值回歸特性） |

共整合比相關性更適合配對交易，因為它保證價差有回歸均值的傾向。

### 常見配對選擇

| 類型 | 範例 |
|------|------|
| 同業龍頭 | 台積電 vs 聯電 |
| 上下游 | 台積電 vs 日月光 |
| 替代品 | 統一 vs 味全 |
| ETF vs 成分股 | 0050 vs 台積電 |

### 風險管理

- **停損 Z-Score**：通常設在 ±3.5，超過此值可能代表共整合關係已破裂
- **回溯期間**：用較長的歷史資料（2~3 年）做共整合檢定更穩健
- **定期重新檢定**：共整合關係可能隨時間改變，建議每季重新驗證
