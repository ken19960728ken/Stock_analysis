# 風險管理

## 功能概述

提供持倉管理與組合風險分析功能。使用者可輸入目前的持股部位，系統自動計算風險指標、回撤分析、相關性矩陣與報酬分佈，協助投資人全面評估持倉風險。

## 操作介面

### 持倉管理

在 Sidebar 的表單中新增持倉：

| 輸入項 | 說明 |
|--------|------|
| 股票 | 從全市場股票清單選擇 |
| 股數 | 持有股數 |
| 成本價 | 每股平均成本（元） |

支援新增多筆持倉，以及一鍵清除全部持倉。

## 分析模組

### 1. 持倉總覽

**4 個 Metric 卡片**：

| Metric | 計算方式 |
|--------|---------|
| 總市值 | Σ(現價 × 股數) |
| 總損益 | Σ((現價 - 成本) × 股數)，含損益百分比 |
| 持股檔數 | 持倉中的股票數量 |
| 總成本 | Σ(成本 × 股數) |

**持倉明細表**：

| 欄位 | 說明 |
|------|------|
| 標的 | 股票代碼 + 名稱 |
| 股數 | 持有股數 |
| 成本價 | 每股平均成本 |
| 現價 | 最新收盤價 |
| 市值 | 現價 × 股數 |
| 損益 | (現價 - 成本) × 股數 |
| 損益% | (現價 - 成本) / 成本 × 100% |

### 2. 風險指標

**7 個核心風險 Metric**：

| 指標 | 公式 | 說明 |
|------|------|------|
| VaR (95%) | 歷史模擬法，取日報酬率第 5 百分位 | 95% 信心水準下，單日最大預期損失 |
| CVaR (95%) | VaR 以下報酬率的平均值 | 尾部風險的期望損失（比 VaR 更保守） |
| Sharpe Ratio | (年化報酬 - 1.5%) / 年化波動率 | 每承擔 1 單位風險的超額報酬，> 1 為佳 |
| Sortino Ratio | (年化報酬 - 1.5%) / 下行波動率 | 只考慮下行風險的 Sharpe，> 1.5 為佳 |
| 年化波動率 | 日報酬標準差 × √252 | 年化後的價格波動程度 |
| Beta | 股票日報酬對大盤日報酬的回歸斜率 | 系統性風險，> 1 表示波動大於大盤 |
| Alpha | 年化(實際報酬 - 預期報酬) | Jensen's Alpha，> 0 表示有超額報酬 |

### 3. 回撤分析

**3 個 Metric**：

| 指標 | 說明 |
|------|------|
| 最大回撤 | 從高點到低點的最大跌幅（%） |
| 回撤持續天數 | 從回撤開始到恢復前高的最長天數 |
| Calmar Ratio | 年化報酬 / 最大回撤，> 1 為佳 |

**圖表**：權益曲線（上方）+ 水下回撤圖（下方，紅色填充區域）

### 4. 相關性矩陣

**圖表**：持倉股票間的相關性熱力圖（RdBu_r 色彩）

| 相關性 | 意義 |
|--------|------|
| > 0.7 | 高度正相關，風險集中 |
| 0.3 ~ 0.7 | 中度相關 |
| < 0.3 | 低相關，分散效果好 |
| < 0 | 負相關，天然避險 |

**集中度警示**：當任兩檔持股相關性 > 0.5 時，系統會顯示警告訊息。

## 風險指標解讀指南

### VaR 與 CVaR

```
例：VaR(95%) = -2.5%
→ 有 95% 的把握，單日損失不超過 2.5%
→ 但有 5% 的機率，損失會超過 2.5%

CVaR(95%) = -3.8%
→ 在那 5% 的極端情況中，平均損失為 3.8%
```

### Sharpe vs Sortino

| 指標 | 適用場景 |
|------|---------|
| Sharpe | 通用的風險調整報酬指標，假設報酬對稱分佈 |
| Sortino | 適合非對稱分佈（上漲不算風險），更貼近投資人感受 |

### 最大回撤的意義

| 最大回撤 | 風險等級 | 說明 |
|----------|---------|------|
| < 10% | 低風險 | 保守型組合 |
| 10~20% | 中等風險 | 均衡型組合 |
| 20~30% | 較高風險 | 積極型組合 |
| > 30% | 高風險 | 需檢視是否過度集中 |
