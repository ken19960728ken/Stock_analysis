# 回測引擎

## 功能概述

提供完整的策略回測功能，支援 16 個內建策略，每個策略可自訂參數。回測引擎計入台灣市場的手續費、證交稅與滑價成本，並以 0050 買入持有作為基準比較。

## 操作介面

### Sidebar 設定

| 設定項 | 預設值 | 說明 |
|--------|--------|------|
| 股票選擇 | — | 從全市場股票清單選擇 |
| 策略選擇 | — | 16 個內建策略（動態載入 STRATEGY_MAP） |
| 策略參數 | 各策略預設值 | 依據策略動態生成參數輸入欄位 |
| 開始日期 | 3 年前 | 回測起始日 |
| 結束日期 | 今天 | 回測結束日 |
| 初始資金 | 1,000,000 | 起始資金（元） |
| 手續費率 | 0.1425% | 台灣券商標準手續費（買賣各收一次） |
| 證交稅率 | 0.3% | 賣出時收取（ETF 為 0.1%） |
| 滑價 | 0.1% | 模擬市場衝擊成本 |

## 回測流程

```
1. 載入股票歷史資料（日K + 需要的基本面/籌碼資料）
2. 策略產生訊號（signal: 1=買, -1=賣, 0=持有）
3. 模擬交易執行（含成本計算）
4. 計算績效指標
5. 載入 0050 同期資料作為基準
6. 生成報告（指標 + 圖表 + 交易明細）
```

## 績效指標（10 項）

| 指標 | 公式/說明 |
|------|----------|
| 總報酬率 | (期末淨值 - 初始資金) / 初始資金 × 100% |
| 年化報酬率 | (1 + 總報酬率)^(252/交易天數) - 1 |
| Sharpe Ratio | (年化報酬 - 無風險利率) / 年化波動率，無風險利率 = 1.5% |
| Sortino Ratio | (年化報酬 - 無風險利率) / 下行波動率 |
| 最大回撤 | max((Peak - Trough) / Peak)，從高點到低點的最大跌幅 |
| 回撤持續天數 | 從回撤開始到恢復前高的最長天數 |
| 交易次數 | 完成的買賣來回次數 |
| 勝率 | 獲利交易次數 / 總交易次數 × 100% |
| 獲利因子 | 總獲利金額 / 總虧損金額 |
| 平均持有天數 | 所有交易的平均持有天數 |

## 0050 基準比較

自動載入同期間 0050（元大台灣50）的日K資料，計算買入持有策略的：
- 總報酬率
- 年化報酬率
- Sharpe Ratio
- 最大回撤

## 視覺化報告

### 權益曲線

雙折線圖顯示策略淨值與 0050 基準的走勢比較，下方附帶水下回撤圖（Drawdown Curve）。

### 交易標記 K 線圖

在 K 線圖上以三角形標記買賣點：
- 綠色向上三角 ▲ = 買入訊號
- 紅色向下三角 ▼ = 賣出訊號

### 月報酬率熱力圖

年 × 月矩陣形式呈現每月報酬率，使用 RdYlGn 色彩：
- 綠色 = 正報酬
- 紅色 = 負報酬

### 交易明細表

| 欄位 | 說明 |
|------|------|
| 買入日期 | 進場日期 |
| 買入價格 | 進場價格（含滑價） |
| 賣出日期 | 出場日期 |
| 賣出價格 | 出場價格（含滑價） |
| 持有天數 | 持有期間 |
| 報酬率 | 單筆交易報酬率（扣除成本） |
| 損益金額 | 單筆交易損益（元） |

支援 CSV 匯出。

## 成本模型

### 台灣股市交易成本

```
買入成本 = 股價 × (1 + 手續費率 + 滑價)
賣出收入 = 股價 × (1 - 手續費率 - 證交稅率 - 滑價)
單趟來回成本 ≈ 0.1425% × 2 + 0.3% + 0.1% × 2 = 0.785%
```

### 策略一覽表

未執行回測時，頁面顯示所有 16 個內建策略的一覽表，包含策略名稱、說明、參數列表。詳細的策略參數說明請參閱 [策略參數詳解](策略參數詳解.md)。
