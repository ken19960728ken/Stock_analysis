# 策略參數詳解

本文件詳細說明 16 個內建策略的每個參數意義、預設值、合理範圍與調參建議。

---

## 一、技術面策略（7 個）

---

### 1. MA 交叉（MACrossStrategy）

**核心邏輯**：短期均線上穿長期均線時買入（黃金交叉），下穿時賣出（死亡交叉）。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `fast_period` | 5 | int | 快速均線週期（短天期 SMA） |
| `slow_period` | 20 | int | 慢速均線週期（長天期 SMA） |

**參數詳解**：

- **`fast_period`**（快速均線週期）
  - 代表短期趨勢方向，越小越靈敏、訊號越多但雜訊也越多
  - 常用值：5（一週）、10（兩週）、20（一個月）
  - 建議範圍：3 ~ 30

- **`slow_period`**（慢速均線週期）
  - 代表中長期趨勢方向，越大越穩定但反應越慢
  - 常用值：20（一個月）、60（一季）、120（半年）、240（一年）
  - 建議範圍：20 ~ 240
  - **必須大於 `fast_period`**

**經典組合**：
| 組合 | 特性 |
|------|------|
| 5/20 | 短線操作，訊號頻繁 |
| 10/60 | 中線波段，適合月操作 |
| 20/60 | 中線趨勢，穩健型 |
| 60/240 | 長線趨勢，年度級別 |

### 2. MACD 訊號（MACDStrategy）

**核心邏輯**：MACD Histogram 由負轉正時買入，由正轉負時賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `fast` | 12 | int | 快線 EMA 週期 |
| `slow` | 26 | int | 慢線 EMA 週期 |
| `signal` | 9 | int | 訊號線 EMA 週期 |

**參數詳解**：

- **`fast`**（快線 EMA 週期）
  - 計算 MACD Line 的短期 EMA
  - 12 是 Gerald Appel 原始設計值，約 2.5 週
  - 縮小會讓 MACD 更靈敏，放大會讓 MACD 更平滑
  - 建議範圍：8 ~ 20

- **`slow`**（慢線 EMA 週期）
  - 計算 MACD Line 的長期 EMA
  - 26 是原始設計值，約 5 週
  - 建議範圍：20 ~ 40
  - **必須大於 `fast`**

- **`signal`**（訊號線 EMA 週期）
  - 對 MACD Line 再做一次 EMA 平滑
  - 9 是原始設計值
  - 越小越靈敏但假訊號多，越大越遲鈍但訊號可靠
  - 建議範圍：5 ~ 15

**MACD 計算公式**：
```
MACD Line = EMA(fast) - EMA(slow)
Signal Line = EMA(MACD Line, signal)
Histogram = MACD Line - Signal Line
```

### 3. Bollinger 突破（BollingerStrategy）

**核心邏輯**：價格觸及下軌時買入（超跌反彈），觸及上軌時賣出（超漲回落）。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `period` | 20 | int | 布林通道計算週期 |
| `std_dev` | 2.0 | float | 標準差倍數 |

**參數詳解**：

- **`period`**（布林通道週期）
  - 中軌 SMA 的計算天數，也是標準差的計算窗口
  - 20 是 John Bollinger 建議值（約一個月交易日）
  - 越大通道越寬，訊號越少
  - 建議範圍：10 ~ 50

- **`std_dev`**（標準差倍數）
  - 決定上下軌與中軌的距離
  - 2.0 表示約 95% 的價格落在通道內（常態分佈假設）
  - 1.5 → 更窄通道，訊號更頻繁
  - 2.5 → 更寬通道，只捕捉極端情況
  - 建議範圍：1.5 ~ 3.0

**通道寬度的意義**：
- 通道收窄（Squeeze）→ 波動降低，可能即將突破
- 通道擴張 → 波動增大，趨勢正在進行

### 4. RSI 反轉（RSIReversalStrategy）

**核心邏輯**：RSI 進入超賣區後回升時買入，進入超買區後回落時賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `period` | 14 | int | RSI 計算週期 |
| `oversold` | 30 | int | 超賣門檻 |
| `overbought` | 70 | int | 超買門檻 |

**參數詳解**：

- **`period`**（RSI 計算週期）
  - Welles Wilder 原始建議值為 14
  - 使用 Wilder Smoothing（等效於 2N-1 天的 EMA）
  - 越小波動越大、越靈敏；越大越平滑
  - 建議範圍：7 ~ 21

- **`oversold`**（超賣門檻）
  - RSI 低於此值視為超賣（市場過度恐慌）
  - 30 是經典值，強勢股可用 40，弱勢股可用 20
  - 建議範圍：20 ~ 40

- **`overbought`**（超買門檻）
  - RSI 高於此值視為超買（市場過度樂觀）
  - 70 是經典值，強勢股可用 80，弱勢股可用 60
  - 建議範圍：60 ~ 80

**注意事項**：
- 強趨勢行情中 RSI 可能長期維持在超買/超賣區，反轉策略效果不佳
- 適合盤整行情使用

### 5. Parabolic SAR（ParabolicSARStrategy）

**核心邏輯**：SAR 點從價格上方翻到下方（翻多）時買入，從下方翻到上方（翻空）時賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `af` | 0.02 | float | 加速因子初始值 |
| `max_af` | 0.2 | float | 加速因子上限 |

**參數詳解**：

- **`af`**（加速因子初始值，Acceleration Factor）
  - SAR 追蹤速度的起始值，每次創新高/低時增加一個 `af`
  - 0.02 是 Welles Wilder 原始設計值
  - 越大 → SAR 追蹤越快，停損越緊，但容易被震盪洗出
  - 越小 → SAR 追蹤越慢，可抓住大趨勢，但停損較遠
  - 建議範圍：0.01 ~ 0.05

- **`max_af`**（加速因子上限）
  - 限制 AF 的最大值，防止 SAR 追蹤速度無限加快
  - 0.2 是原始設計值，表示最多加速 10 次（0.02 × 10）
  - 建議範圍：0.1 ~ 0.3

**SAR 計算流程**：
```
1. 初始 AF = 0.02，EP = 極值點
2. SAR(t+1) = SAR(t) + AF × (EP - SAR(t))
3. 若創新高/低：AF += 0.02（不超過 max_af），更新 EP
4. 若價格穿越 SAR：翻轉方向，重置 AF
```

### 6. Heikin-Ashi（HeikinAshiStrategy）

**核心邏輯**：HA K 線由陰轉陽（含連續確認）時買入，由陽轉陰時賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `confirm_bars` | 2 | int | 連續確認 K 棒數 |

**參數詳解**：

- **`confirm_bars`**（連續確認 K 棒數）
  - 轉換方向後需連續 N 根同方向 HA K 棒才確認訊號
  - 2 表示至少連續 2 根陽線才買入（避免假突破）
  - 1 → 最靈敏，可能有較多假訊號
  - 3 → 更保守，會錯過行情初段但訊號更可靠
  - 建議範圍：1 ~ 4

**Heikin-Ashi 的特點**：
- HA K 線平滑了原始價格波動，趨勢更容易辨識
- 連續陽線（HA_Close > HA_Open）→ 上漲趨勢
- 連續陰線（HA_Close < HA_Open）→ 下跌趨勢
- 不適合用來判斷精確的進出場價格（HA 價格非實際成交價）

### 7. Dual Thrust（DualThrustStrategy）

**核心邏輯**：基於前 N 日的高低點計算動態上下軌，突破上軌買入，跌破下軌賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `lookback` | 5 | int | 計算區間 N 日 |
| `k1` | 0.5 | float | 上軌係數 |
| `k2` | 0.5 | float | 下軌係數 |

**參數詳解**：

- **`lookback`**（計算區間 N 日）
  - 回溯 N 日計算最高價與最低價的 Range
  - 越大 → 通道越寬，訊號越少但越可靠
  - 越小 → 通道越窄，訊號越多但假突破多
  - 建議範圍：3 ~ 10

- **`k1`**（上軌係數）
  - 上軌 = 開盤價 + k1 × Range
  - 越大 → 上軌越高，需要更大漲幅才觸發買入
  - 建議範圍：0.3 ~ 0.8

- **`k2`**（下軌係數）
  - 下軌 = 開盤價 - k2 × Range
  - 越大 → 下軌越低，需要更大跌幅才觸發賣出
  - 建議範圍：0.3 ~ 0.8
  - **k1 ≠ k2 可實現非對稱突破**（例如容易做多但不容易做空）

**Range 計算**：
```
HH = max(High, N日)
HC = max(Close, N日)
LL = min(Low, N日)
LC = min(Close, N日)
Range = max(HH - LC, HC - LL)
```

### 8. 法人跟單（InstitutionalStrategy）

**核心邏輯**：三大法人連續 N 日淨買超時買入，連續 N 日淨賣超時賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `consecutive_days` | 3 | int | 連續天數門檻 |

**參數詳解**：

- **`consecutive_days`**（連續天數門檻）
  - 法人必須連續 N 天買超才觸發買入訊號
  - 3 天是常見設定，代表法人有明確的佈局意圖
  - 1 → 太靈敏，法人一天買超就買入，雜訊多
  - 5 → 較保守，會錯過短線機會但確認度高
  - 建議範圍：2 ~ 7

**注意事項**：
- 法人包含外資、投信、自營商三者合計
- 大型股法人影響力較大，中小型股效果可能不明顯
- 需搭配成交量觀察，低量的法人買超可能不具參考性

---

### 9. 融資融券訊號（MarginSignalStrategy）

**核心邏輯**：融資餘額減少且股價上漲 → 籌碼沉澱（散戶退出、主力介入），產生買入訊號。融資暴增且股價下跌 → 散戶追多被套，產生賣出訊號。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `margin_change_pct` | -5.0 | float | 融資餘額變化門檻（%） |
| `lookback_days` | 5 | int | 回溯天數 |

**參數詳解**：

- **`margin_change_pct`**（融資餘額變化門檻）
  - 負值代表融資減少的幅度門檻
  - -5.0 表示融資餘額在回溯期間減少超過 5% 才觸發
  - -3.0 → 更寬鬆，較小的融資減少就觸發
  - -10.0 → 更嚴格，需要大幅度的融資減少
  - 建議範圍：-15.0 ~ -2.0

- **`lookback_days`**（回溯天數）
  - 比較融資餘額變化的時間窗口
  - 5 天 → 約一週，捕捉短線籌碼變化
  - 10 天 → 約兩週，更穩定的趨勢
  - 建議範圍：3 ~ 20

**買入條件**：`融資變化 <= margin_change_pct` 且 `股價上漲`
**賣出條件**：`融資大幅增加` 且 `股價下跌`

### 10. 股權集中度（OwnershipConcentrationStrategy）

**核心邏輯**：大股東持股比例增加 + 股東人數減少 → 籌碼集中在大戶手中 → 買入。反之（大股東減持 + 散戶增加）→ 賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `holder_increase_threshold` | 1.0 | float | 持股比例增加門檻（百分點） |
| `shareholder_decrease_threshold` | -3.0 | float | 股東人數變化門檻（%） |
| `lookback_periods` | 4 | int | 回溯期數 |

**參數詳解**：

- **`holder_increase_threshold`**（持股比例增加門檻）
  - 大股東（400 張以上）持股比例需增加的百分點數
  - 1.0 表示持股比例從 25% 增加到 26% 以上才觸發
  - 0.5 → 更靈敏
  - 2.0 → 更嚴格，需明顯的大量買入
  - 建議範圍：0.3 ~ 3.0

- **`shareholder_decrease_threshold`**（股東人數變化門檻）
  - 股東人數需減少的比例（負值）
  - -3.0 表示股東人數需減少 3% 以上
  - -1.0 → 更靈敏
  - -5.0 → 更嚴格
  - 建議範圍：-10.0 ~ -1.0

- **`lookback_periods`**（回溯期數）
  - 與幾期前的數據比較（資料通常為週頻）
  - 4 表示與 4 週前比較
  - 建議範圍：2 ~ 8

**注意事項**：
- 股權分散表為每週公布一次，資料頻率較低
- 需與價量配合觀察，籌碼集中但股價不動可能是主力在吸貨階段

## 三、基本面策略（3 個）

### 11. 價值投資（ValueInvestingStrategy）

**核心邏輯**：同時滿足低本益比、高殖利率、營收正成長三個條件時買入。任一條件不滿足時賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `pe_threshold` | 15 | int | P/E 低估門檻 |
| `dividend_yield_threshold` | 3.0 | float | 殖利率最低要求（%） |
| `revenue_growth_threshold` | 0 | int | 營收成長門檻（%） |

**參數詳解**：

- **`pe_threshold`**（P/E 低估門檻）
  - 本益比需低於此值才視為低估
  - 15 是台股傳統的合理水位（約 6.7% 盈餘殖利率）
  - 10 → 非常嚴格，只選極度低估股
  - 20 → 較寬鬆，涵蓋穩健成長股
  - 建議範圍：8 ~ 25
  - 不同產業合理 P/E 差異大：金融 8~12、傳產 10~15、科技 15~25

- **`dividend_yield_threshold`**（殖利率最低要求）
  - 現金殖利率需高於此值
  - 3.0% 是台股平均水準
  - 4.0% → 偏高息導向
  - 2.0% → 較寬鬆
  - 建議範圍：2.0 ~ 6.0

- **`revenue_growth_threshold`**（營收成長門檻）
  - 最新月營收年增率需高於此值（%）
  - 0 表示營收不衰退即可
  - 10 → 要求 10% 以上成長
  - -10 → 容許輕微衰退
  - 建議範圍：-20 ~ 30

### 12. 財報三率（FundamentalRatioStrategy）

**核心邏輯**：計算毛利率、營業利益率、淨利率，當達標條件數 >= min_conditions 時買入。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `gross_margin_threshold` | 25.0 | float | 毛利率門檻（%） |
| `operating_margin_threshold` | 10.0 | float | 營業利益率門檻（%） |
| `net_margin_threshold` | 8.0 | float | 淨利率門檻（%） |
| `min_conditions` | 2 | int | 最少需達標條件數 |

**參數詳解**：

- **`gross_margin_threshold`**（毛利率門檻）
  - 毛利率 = (營收 - 成本) / 營收 × 100%
  - 25% 表示產品有基本的獲利能力
  - 反映產品定價能力與成本控制
  - 建議範圍：15.0 ~ 50.0
  - 產業差異大：IC 設計 40~60%、傳產 10~25%、零售 5~15%

- **`operating_margin_threshold`**（營業利益率門檻）
  - 營業利益率 = 營業利益 / 營收 × 100%
  - 10% 表示本業經營有效率
  - 比毛利率多扣除了管銷費用
  - 建議範圍：5.0 ~ 30.0

- **`net_margin_threshold`**（淨利率門檻）
  - 淨利率 = 稅後淨利 / 營收 × 100%
  - 8% 是整體獲利能力的基本要求
  - 包含業外損益，可能受一次性因素影響
  - 建議範圍：3.0 ~ 25.0

- **`min_conditions`**（最少達標條件數）
  - 三率中至少幾個達標才買入
  - 2 → 寬鬆（2/3 達標即可）
  - 3 → 嚴格（三率全部達標）
  - 1 → 非常寬鬆（任一達標即可）
  - 建議範圍：1 ~ 3

### 13. 自由現金流（FreeCashFlowStrategy）

**核心邏輯**：營運現金流為正且自由現金流殖利率達標時買入。OCF 為負或 FCF Yield 不達標時賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `fcf_yield_threshold` | 5.0 | float | FCF Yield 門檻（%） |
| `ocf_positive_required` | True | bool | 是否要求 OCF > 0 |

**參數詳解**：

- **`fcf_yield_threshold`**（FCF Yield 門檻）
  - FCF Yield = 自由現金流 / 市值 × 100%
  - 自由現金流 = 營運現金流 - 資本支出
  - 5.0% 表示投資人每年可獲得 5% 的自由現金回報
  - 3.0% → 較寬鬆
  - 8.0% → 更嚴格，只選現金流充沛的企業
  - 建議範圍：2.0 ~ 10.0

- **`ocf_positive_required`**（是否要求 OCF > 0）
  - True → 營運現金流必須為正（本業有實際現金流入）
  - False → 不要求，但仍計算 FCF Yield
  - **強烈建議保持 True**：OCF 為負代表本業現金流出，即使帳面獲利也可能有財務風險

**關鍵概念**：
- OCF（營運現金流）> 淨利 → 盈餘品質好（現金收得回來）
- OCF < 淨利 → 盈餘品質差（可能是應收帳款膨脹）
- FCF > 0 → 公司有餘裕發股利、還債或再投資

## 四、複合策略（3 個）

### 14. 多因子綜合（MultiFactorStrategy）

**核心邏輯**：綜合技術面（RSI、MACD、MA 方向）、籌碼面（法人買賣超）、基本面（PER）三大維度加權計算分數，超過門檻買入，低於門檻賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `tech_weight` | 0.4 | float | 技術面權重 |
| `chip_weight` | 0.3 | float | 籌碼面權重 |
| `fund_weight` | 0.3 | float | 基本面權重 |
| `buy_threshold` | 0.6 | float | 買入分數門檻 |
| `sell_threshold` | -0.3 | float | 賣出分數門檻 |
| `use_zscore` | False | bool | 是否啟用 Z-Score 標準化 |

**參數詳解**：

- **`tech_weight`**（技術面權重）
  - 技術面子分數的權重，預設佔比 40%
  - 技術面因子：RSI、MACD Histogram、MA20 方向
  - 建議範圍：0.2 ~ 0.6

- **`chip_weight`**（籌碼面權重）
  - 籌碼面子分數的權重，預設佔比 30%
  - 籌碼面因子：三大法人淨買超
  - 建議範圍：0.1 ~ 0.5

- **`fund_weight`**（基本面權重）
  - 基本面子分數的權重，預設佔比 30%
  - 基本面因子：PER（本益比）
  - 建議範圍：0.1 ~ 0.5
  - **三個權重之和建議 = 1.0**

- **`buy_threshold`**（買入分數門檻）
  - 加權總分超過此值才買入
  - 分數範圍大約在 -1.0 ~ 1.0
  - 0.6 → 需要多數因子同時看多
  - 0.3 → 更寬鬆
  - 建議範圍：0.2 ~ 0.8

- **`sell_threshold`**（賣出分數門檻）
  - 加權總分低於此值才賣出
  - -0.3 → 輕度看空即賣出
  - -0.6 → 需要明確看空才賣出
  - 建議範圍：-0.8 ~ 0.0

- **`use_zscore`**（是否啟用 Z-Score 標準化）
  - False → 各因子使用原始分數（預設行為）
  - True → 各因子先做 Z-Score 標準化再加權
  - Z-Score 會消除不同因子量綱差異，讓權重更公平
  - 啟用後訊號觸發時機可能不同

### 15. 事件驅動（EventDrivenStrategy）

**核心邏輯**：根據特定事件（除息、財報公布）的日期，在事件前 N 天買入、事件後 N 天賣出。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `event_type` | "dividend" | str | 事件類型 |
| `entry_days_before` | 5 | int | 事件前 N 天進場 |
| `exit_days_after` | 10 | int | 事件後 N 天出場 |

**參數詳解**：

- **`event_type`**（事件類型）
  - `"dividend"` → 除息事件（台股 6~9 月為除息旺季）
  - `"earnings"` → 財報公布事件
  - 不同事件類型的價格行為模式不同

- **`entry_days_before`**（事件前進場天數）
  - 在事件日前 N 個交易日買入
  - 5 天 → 約一週前佈局
  - 10 天 → 提前兩週佈局（避免搶填息行情）
  - 建議範圍：1 ~ 20

- **`exit_days_after`**（事件後出場天數）
  - 在事件日後 N 個交易日賣出
  - 10 天 → 約兩週後出場
  - 20 天 → 約一個月後出場（等待填息）
  - 建議範圍：5 ~ 30

**除息策略邏輯**：
- 除息前買入 → 參與除息 → 期待填息後獲利
- 填息速度快的股票 → 策略表現好
- 填息失敗或花很久才填息 → 策略虧損

### 16. 機器學習選股（MLFactorStrategy）

**核心邏輯**：使用 LightGBM 模型對多因子進行非線性組合，預測前瞻 N 天報酬的分位數（好/中/差），選擇預測為最佳分位的股票買入。

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `forward_days` | 5 | int | 前瞻天數 |
| `buy_quantile` | 2 | int | 買入分位標籤 |
| `sell_quantile` | 0 | int | 賣出分位標籤 |

**參數詳解**：

- **`forward_days`**（前瞻天數）
  - 預測未來 N 天的報酬率
  - 5 天 → 約一週，短線交易
  - 10 天 → 約兩週，波段交易
  - 20 天 → 約一個月，中線佈局
  - 建議範圍：5 ~ 20

- **`buy_quantile`**（買入分位標籤）
  - 當模型預測結果為此分位時買入
  - 使用 3 分位時：0=差, 1=中, 2=好
  - 使用 5 分位時：0=最差, ..., 4=最好
  - 預設 2（3 分位中的「好」）
  - 建議：設為最高分位

- **`sell_quantile`**（賣出分位標籤）
  - 當模型預測結果為此分位時賣出
  - 預設 0（3 分位中的「差」）
  - 建議：設為最低分位

**模型特徵**：
| 特徵 | 說明 |
|------|------|
| return_5d | 5 日報酬率 |
| return_20d | 20 日報酬率 |
| volatility_20d | 20 日波動率 |
| volume_ratio | 成交量比（vs 20 日均量） |
| rsi | RSI(14) |
| macd_hist | MACD Histogram |
| ma20_slope | MA20 斜率 |
| bb_pct | Bollinger %B |
| per | 本益比（選用） |
| pbr | 股價淨值比（選用） |
| dividend_yield | 殖利率（選用） |
| institutional_net | 法人淨買超（選用） |

**注意事項**：
- 需要安裝 `lightgbm` 套件（含 libomp 依賴）
- 使用 TimeSeriesSplit CV 避免前瞻偏差
- Walk-Forward 回測提供更真實的績效評估
