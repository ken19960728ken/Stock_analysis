# Bollinger 突破（BollingerStrategy）

> 類型：技術面 ｜ 檔案：`analysis/strategies/bollinger.py`

## 核心邏輯

價格觸及下軌時買入（超跌反彈），觸及上軌時賣出（超漲回落）。

## 參數說明

| 參數 | 預設值 | 型別 | 說明 |
|------|--------|------|------|
| `period` | 20 | int | 布林通道計算週期 |
| `std_dev` | 2.0 | float | 標準差倍數 |

### 參數詳解

- **`period`**（布林通道週期）
  - 中軌 SMA 的計算天數，也是標準差的計算窗口
  - 20 是 John Bollinger 建議值（約一個月交易日）
  - 越大通道越寬，訊號越少
  - 建議範圍：10 ~ 50

- **`std_dev`**（標準差倍數）
  - 決定上下軌與中軌的距離
  - 2.0 表示約 95% 的價格落在通道內（常態分佈假設）
  - 1.5 → 更窄通道，訊號更頻繁
  - 2.5 → 更寬通道，只捕捉極端情況
  - 建議範圍：1.5 ~ 3.0

### 通道寬度的意義

- 通道收窄（Squeeze）→ 波動降低，可能即將突破
- 通道擴張 → 波動增大，趨勢正在進行

## 買賣條件

- **買入**：價格 < 下軌且 RSI < 閾值（超跌回歸）
- **賣出**：價格 > 上軌或 RSI > 閾值

## 學理基礎

John Bollinger 於 1983 年提出布林通道（Bollinger Bands），以 SMA ± K 倍標準差構成動態波動帶。本策略實際上是**均值回歸**策略（價格觸及下軌買入、上軌賣出），而非突破策略。
