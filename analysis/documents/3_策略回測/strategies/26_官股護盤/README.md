# 26. 官股護盤偵測策略

## 策略概述

追蹤 8 大官股行庫（兆豐/第一/華南/臺銀/合庫/土銀/台企銀/彰銀）的買超力道，
在市場下跌且官股買超力道異常放大時買入。

## 學理來源

無直接學術論文。官股護盤為台灣股市特有現象，源自政府透過官股行庫在市場恐慌時進場穩定信心。

## 資料分析發現（Claude 設計）

**關鍵洞察**：官股行庫幾乎**每天都是淨買超**，不論大盤漲跌。

- 錯誤假設：官股買 = 護盤
- 正確判斷：官股買超力道異常放大 + 大盤下跌 = 護盤訊號

**統計驗證**（2024-01 ~ 2026-03，chip_gov_bank 資料）：

- gov_intensity = 今日淨買超 / 20日平均淨買超
- 大跌日(ret<-1.5%): intensity 平均 1.17
- 平盤日(|ret|<0.5%): intensity 平均 -2.17
- 護盤訊號(intensity>1.3 + 跌>1%): 45 次
  - T+5: +0.99%（勝率 72%）
  - T+10: +1.53%（勝率 69%）
  - T+20: +3.10%（勝率 71%）

## 參數

| 參數 | 預設值 | 說明 |
|---|---|---|
| intensity_threshold | 1.3 | 官股力道閾值（今日淨買超 / 20日均值） |
| market_drop_pct | -0.01 | 大盤跌幅門檻（-1%） |
| lookback_days | 20 | 力道均值計算窗口（交易日） |
| max_hold_days | 20 | 最大持有天數 |
| min_banks | 6 | 最少行庫買超數 |

## 買賣條件

**買入**（全部滿足）：
1. gov_intensity > 1.3（買超力道異常放大）
2. 日報酬 < -1%（市場下跌）
3. 買超行庫數 >= 6

**賣出**：
- 持有達 max_hold_days 天自動出場
- 護盤反彈通常為短期行情，不設其他賣出條件

## 資料需求

- `chip_gov_bank` 表：官股行庫每日買賣超明細
- 公布延遲：1 天（隔日公布）
