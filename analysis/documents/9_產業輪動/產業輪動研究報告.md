# 產業輪動研究報告

## 1. 研究動機與目標

台灣股市以電子業為核心，產業輪動是驅動市場報酬的關鍵因子。本研究旨在建構一套系統化的產業輪動分析框架，結合營收動能與法人資金流向兩大維度，協助投資人：

1. **辨識強弱產業**：量化各產業的營收成長動能與法人佈局方向
2. **捕捉輪動趨勢**：透過時間衰減加權與歷史排名追蹤，及早發現產業轉折
3. **分析供應鏈傳導**：利用上下游營收連動關係，預判產業動能的擴散路徑

## 2. 模型方法論

### 2.1 營收動能（Revenue Momentum）

以產業內所有個股的月營收年增率（YoY）為基礎，計算三個統計量：

- **平均 YoY**（`avg_yoy`）：反映產業整體成長強度
- **中位 YoY**（`median_yoy`）：排除極端值後的代表性成長率
- **正成長比例**（`positive_ratio`）：反映產業內的成長普遍程度

綜合評分公式：
```
momentum_score = 0.5 × avg_yoy_percentile + 0.3 × positive_ratio_percentile + 0.2 × median_yoy_percentile
```

### 2.2 法人資金流向（Institutional Flow）

以三大法人（外資、投信、自營商）的淨買賣超金額為基礎：

- **淨買超合計**（`total_net_buy`）：產業吸引法人資金的絕對量
- **平均淨買超**（`avg_net_buy`）：控制產業規模後的法人偏好

評分以排名百分位標準化。

### 2.3 指數衰減加權

傳統模型對回溯期內所有資料點等權處理，但市場狀態持續變化，近期資料的參考價值通常高於遠期。本模型引入指數衰減：

```
weight(t) = exp(-λ × Δt)
λ = ln(2) / half_life
```

| 衰減對象 | 時間單位 | 建議半衰期 | 效果 |
|----------|----------|-----------|------|
| 營收 YoY | 月 | 2 個月 | 2 個月前權重 50%，4 個月前 25% |
| 法人淨買超 | 天 | 7 天 | 一週前權重 50%，兩週前 25% |

**設計原則**：
- `decay_half_life=None` 時完全不衰減，行為與原版一致
- 半衰期越短 → 模型越敏感 → 適合快速輪動期
- 半衰期越長 → 模型越穩定 → 適合趨勢持續期

### 2.4 ICIR 動態權重

靜態的 50/50 權重假設營收動能與法人流向同等重要，但實際效果會隨市場環境變化。透過計算各因子的歷史 IC（Information Coefficient）與 ICIR（IC / std(IC)），可動態調整權重：

- IC 高且穩定的因子 → 給予更高權重
- IC 不穩定或為負的因子 → 降低權重

實作上可搭配 `dynamic_weights.py` 的 `ic_decay_weights` 模式，將滾動 IC 轉換為動態權重後傳入 `industry_composite_score(dynamic_weights=...)`。

### 2.5 綜合得分

```
composite_score = m_weight × momentum_score + f_weight × flow_score
```

其中 `m_weight + f_weight = 1.0`，可由使用者手動設定或由 ICIR 動態調整。

## 3. 供應鏈分析框架

### 3.1 設計理念

台灣產業結構高度垂直整合，上下游營收存在明顯的領先/落後關係。供應鏈分析透過定義上下游順序，計算各環節的營收動能傳導效應。

### 3.2 供應鏈清單（13 條）

#### 電子業（4 條）

| 供應鏈 | 上游 → 下游 | 傳導邏輯 |
|--------|------------|----------|
| 半導體 | IC 設計 → 晶圓代工 → IC 製造 → IC 封測 → 導線架 | 設計完成 → 投片 → 製造 → 封裝測試 |
| 電子組裝 | PCB → 被動元件 → 連接器 → 電源 → 主機板 → 伺服器 → NB → 系統 | 零組件 → 模組 → 系統整合 |
| 面板 | LED → TFT-LCD → 光通訊 | 背光源 → 面板 → 光學傳輸 |
| 通訊 | 網路設備 → 電信設備 → 行動電話 | 基礎建設 → 設備 → 終端 |

#### 消費電子（1 條）

| 供應鏈 | 上游 → 下游 | 傳導邏輯 |
|--------|------------|----------|
| 消費電子 | LED → 光通訊 → 消費性電子 → 行動電話 → 資訊通路 | 零組件 → 產品 → 通路銷售 |

#### 傳統產業（8 條）

| 供應鏈 | 上游 → 下游 | 傳導邏輯 |
|--------|------------|----------|
| 汽車 | 汽車零件 → 整車 | 零件供應 → 整車組裝 |
| 化學工業 | 塑化原料 → 電子化學 → 特用化學 | 基礎原料 → 中間品 → 特殊應用 |
| 生技醫療 | 原料藥/學名藥 → 新藥研發 → 醫材 → 醫美/保健 | 原料 → 研發 → 器材 → 終端應用 |
| 鋼鐵 | 鋼鐵 → 不鏽鋼 → 特殊鋼/合金 | 基礎鋼材 → 特殊材料 |
| 食品 | 飼料/油脂 → 食品加工 → 飲料/乳品 | 原料 → 加工 → 終端飲食 |
| 航運 | 貨櫃航運 → 散裝航運 → 航空 | 海運貨物 → 散貨 → 客運/空運 |
| 建築 | 營造 → 建設/房地產 | 施工 → 開發銷售 |
| 紡織 | 機能布/紡紗 → 成衣/代工 | 布料生產 → 成品製造 |

### 3.3 分析方法

**營收動能傳導**：計算供應鏈各環節的近 N 個月平均 YoY，觀察上游動能是否已傳導至下游。

**領先落後矩陣**：使用交叉相關分析（Cross-Correlation），在 ±6 個月的 lag 範圍內尋找最大相關的領先/落後月數。正值代表行環節領先列環節。

## 4. 台灣產業輪動特性

### 4.1 半導體主導

台積電及其供應鏈佔台股權重超過 30%，半導體景氣循環是台股最重要的輪動驅動力。半導體供應鏈通常呈現「IC 設計領先 → 晶圓代工跟進 → 封測收尾」的傳導模式。

### 4.2 傳產的景氣週期

鋼鐵、化學、航運等傳產股受全球大宗商品價格與中國需求影響，通常在景氣擴張後期表現最佳。食品、紡織等內需型產業則具防禦性，在市場下跌時相對抗跌。

### 4.3 法人偏好的變化

外資偏好大型權值股（半導體、金融），投信偏好中小型成長股（IC 設計、電子零組件）。法人流向的分歧往往是產業輪動的先行指標。

### 4.4 季節性因素

- Q1：營收淡季，去年基期影響 YoY
- Q2-Q3：電子業拉貨旺季，半導體/電子組裝動能通常最強
- Q4：消費旺季，品牌/通路受惠

## 5. 應用建議

### 5.1 搭配次產業輪動策略

產業輪動分析的結果可直接對接 `SubIndustryRotationStrategy`：
1. 使用產業排名前 N 的次產業作為候選池
2. 在候選池內選擇個股建倉
3. 定期（月度）重新計算排名並調倉

### 5.2 供應鏈傳導的應用

1. **早期佈局**：當半導體上游（IC 設計）營收加速，但下游（封測）尚未反映時，可提前佈局下游
2. **確認擴散**：當整條供應鏈的各環節 YoY 同步上升，確認景氣擴張
3. **風險警示**：當上游已開始放緩但下游仍在加速，注意營收動能可能即將反轉

### 5.3 衰減加權的使用時機

| 市場狀態 | 建議衰減設定 | 原因 |
|----------|-------------|------|
| 快速輪動 | 半衰期短（營收 1-2 月、法人 3-5 天） | 需快速反映最新狀況 |
| 趨勢持續 | 半衰期長或不衰減（營收 4-6 月、法人 14-30 天） | 避免過度反應短期雜訊 |
| 不確定 | 預設不衰減 | 保守策略，等確認趨勢後再啟用 |

## 6. 已知限制與未來方向

### 6.1 已知限制

- **營收資料滯後**：月營收公布時間為次月 10 號，有 1 個月以上的滯後
- **次產業覆蓋不全**：`sub_industry_mapping.json` 目前覆蓋約 58 個次產業（110+ 個中的一部分），部分冷門次產業缺少足夠股票
- **供應鏈定義的主觀性**：上下游順序依據產業常識定義，非數據驅動
- **法人資料限制**：三大法人資料不含自然人，無法完整反映市場資金流向

### 6.2 未來方向

1. **數據驅動的供應鏈發現**：使用 Granger 因果檢定自動發現產業間的領先/落後關係
2. **加入估值維度**：將 PER/PBR 變化納入產業評分，避免追高估值已極端的產業
3. **事件驅動整合**：結合除息、財報公布等事件，捕捉短期產業輪動機會
4. **跨市場連動**：加入美股/日股產業指數作為領先指標
5. **機器學習模型**：使用 LightGBM 等模型學習最佳的因子權重組合
