# 產業輪動模型

## 功能概述

透過營收動能、法人資金流向、估值面三大維度，計算各產業的綜合強弱排名。支援兩層產業分類（大類 sector + 次產業 sub_industry），提供產業排名表、輪動熱力圖、成分股明細、供應鏈分析四種分析視角，協助投資人掌握資金在不同產業間的輪動趨勢。

## 分析維度

### 1. 營收動能（Revenue Momentum）

**計算方式**：
```
1. 取各產業近 N 個月的所有個股月營收 YoY
2. 計算各產業的統計量：
   - avg_yoy：平均月營收年增率
   - median_yoy：中位數月營收年增率
   - positive_ratio：YoY > 0 的個股比例
3. 綜合評分 momentum_score = avg_yoy × 0.4 + median_yoy × 0.3 + positive_ratio × 0.3
4. 依 momentum_score 降冪排名
```

**判讀**：
- 平均 YoY 高 + positive_ratio 高 → 全產業普遍成長，動能強
- 平均 YoY 高但 positive_ratio 低 → 少數龍頭拉抬，產業分化
- 排名上升 → 產業動能轉強，資金可能流入

### 2. 法人資金流向（Institutional Flow）

**計算方式**：
```
1. 取各產業近 N 天的所有個股法人淨買賣超
2. 計算各產業的統計量：
   - total_net_buy：法人淨買超合計（千元）
   - avg_net_buy：平均每檔法人淨買超
3. 綜合評分 flow_score = 基於排名的標準化分數
4. 依 flow_score 降冪排名
```

**判讀**：
- total_net_buy 大 → 法人積極佈局該產業
- 連續數週淨買超 → 法人中長線看好
- 突然大量賣超 → 法人撤出，需警戒

### 3. 估值面（Valuation）

**計算方式**：
1. 取各產業內所有個股的最新 PER、PBR、殖利率
2. 排除 PER 為負值或 NaN 的股票；產業內有效股票 < 3 的排除該產業
3. 計算各產業的 PER 中位數、PBR 中位數、殖利率中位數
4. 跨產業百分位排名（PER/PBR 反向、殖利率正向）
5. 估值得分 = (1 - PER 百分位) × 0.5 + (1 - PBR 百分位) × 0.3 + 殖利率百分位 × 0.2

**判讀**：
- 估值得分高 → 產業整體低估，投資價值高
- 估值得分低 → 產業估值偏高，追漲風險大
- 搭配營收動能 → 低估 + 高動能 = 最佳組合

### 4. 綜合得分（Composite Score）

```
composite_score = momentum_score × m_weight + flow_score × f_weight + valuation_score × v_weight
（valuation=None 時退化為二因子）
final_rank = 依 composite_score 排名（越小越好）
```

**功能**：分析產業間的營收動能連動關係，發現領先/落後的供應鏈傳導效應。

**分析內容**：

**資料來源**：`supply_chain.py`（營收動能傳導、領先落後矩陣）

### 自動發現（Granger 因果）

**原理**：Granger 因果檢定（1969）— 若時間序列 X 的歷史值能顯著提升對 Y 的預測能力（F-test），
則 X「Granger-causes」Y。對所有次產業 pair 執行檢定，自動偵測營收連動關係。

**操作**：
1. 在 Tab 4 選擇「自動發現（Granger 因果）」
2. 設定最大滯後期數（1-6 月）和顯著性門檻（p < 0.01/0.05/0.10）
3. 點擊「執行 Granger 檢定」

**輸出**：
- 因果網絡圖（節點 = 次產業，邊 = 因果關係，邊寬 = F-stat）
- 顯著因果關係表格（source → target, lag, F-stat, p-value）
- 自動發現的供應鏈列表（DAG 拓撲排序，最長路徑）

**快取**：結果快取至 `data_cache/granger_results.json`，7 天內不重算。

## 產業輪動的概念

### 景氣循環與產業輪動

| 景氣階段 | 特徵 | 通常強勢產業 |
|----------|------|-------------|
| 復甦初期 | 利率低、信貸寬鬆 | 金融、不動產 |
| 擴張期 | 企業獲利改善 | 科技、可選消費 |
| 景氣高峰 | 通膨上升、需求旺盛 | 能源、原物料 |
| 衰退期 | 經濟放緩 | 必需消費、醫療 |

- 金融股受利率政策影響

## 模型改進

### 指數衰減加權

營收動能與法人流向的計算可啟用時間衰減加權，讓近期資料的影響力大於遠期。

**原理**：使用指數衰減函數 `weight = exp(-λ × Δt)`，其中 `λ = ln(2) / half_life`。

| 參數 | 衰減對象 | 單位 | 預設 |
|------|----------|------|------|
| `decay_half_life`（營收） | 月營收 YoY | 月 | None（不衰減） |
| `decay_half_life`（法人） | 法人淨買超 | 天 | None（不衰減） |

**效果**：
- 半衰期 = 2 個月 → 2 個月前的資料權重降為 50%，4 個月前降為 25%
- 半衰期 = 7 天 → 7 天前的法人資料權重降為 50%，14 天前降為 25%
- `decay_half_life=None` 時行為與原版完全一致（向後相容）

**適用場景**：市場快速輪動時期，開啟衰減可讓排名更敏感地反映近期變化。

### ICIR 動態權重調整

`industry_composite_score()` 新增 `dynamic_weights` 參數，允許根據歷史 IC（Information Coefficient）動態調整營收動能與法人流向的權重。

```python
dynamic_weights = {"momentum": 0.6, "flow": 0.4}
composite = industry_composite_score(momentum, flow, dynamic_weights=dynamic_weights)
```

可搭配 `analysis/utils/dynamic_weights.py` 的 IC 衰減權重計算，實現自適應權重。
