# 產業輪動模型

## 功能概述

透過營收動能與法人資金流向兩大維度，計算各產業的綜合強弱排名。支援兩層產業分類（大類 sector + 次產業 sub_industry），提供產業排名表、輪動熱力圖、成分股明細、供應鏈分析四種分析視角，協助投資人掌握資金在不同產業間的輪動趨勢。

## 操作介面

### Sidebar 設定

| 設定項 | 範圍 | 預設 | 說明 |
|--------|------|------|------|
| 營收回溯月數 | 1 ~ 12 | 3 | 計算月營收 YoY 的回溯月數 |
| 法人流向回溯天數 | 5 ~ 60 | 20 | 計算法人淨買超的回溯天數 |
| 營收動能權重 | 0.0 ~ 1.0 | 0.5 | 營收動能在綜合得分中的權重 |
| 輪動歷史月數 | 3 ~ 24 | 12 | 輪動熱力圖的顯示月數 |
| 產業層級 | sector / sub_industry | sector | 選擇使用大類或次產業分類 |

**法人流向權重 = 1 - 營收動能權重**（自動計算）

## 分析維度

### 1. 營收動能（Revenue Momentum）

**計算方式**：
```
1. 取各產業近 N 個月的所有個股月營收 YoY
2. 計算各產業的統計量：
   - avg_yoy：平均月營收年增率
   - median_yoy：中位數月營收年增率
   - positive_ratio：YoY > 0 的個股比例
3. 綜合評分 momentum_score = avg_yoy × 0.4 + median_yoy × 0.3 + positive_ratio × 0.3
4. 依 momentum_score 降冪排名
```

**判讀**：
- 平均 YoY 高 + positive_ratio 高 → 全產業普遍成長，動能強
- 平均 YoY 高但 positive_ratio 低 → 少數龍頭拉抬，產業分化
- 排名上升 → 產業動能轉強，資金可能流入

### 2. 法人資金流向（Institutional Flow）

**計算方式**：
```
1. 取各產業近 N 天的所有個股法人淨買賣超
2. 計算各產業的統計量：
   - total_net_buy：法人淨買超合計（千元）
   - avg_net_buy：平均每檔法人淨買超
3. 綜合評分 flow_score = 基於排名的標準化分數
4. 依 flow_score 降冪排名
```

**判讀**：
- total_net_buy 大 → 法人積極佈局該產業
- 連續數週淨買超 → 法人中長線看好
- 突然大量賣超 → 法人撤出，需警戒

### 3. 綜合得分（Composite Score）

```
composite_score = momentum_rank × m_weight + flow_rank × f_weight
final_rank = 依 composite_score 排名（越小越好）
```

## Tab 2：輪動熱力圖

**矩陣格式**：月份（列）× 產業（欄），數值 = 排名

- 使用 RdYlGn_r 色彩（排名小=綠色=好，排名大=紅色=差）
- 可觀察各產業排名隨時間的變化趨勢
- 某產業排名持續向上（數字變小）→ 產業轉強
- 某產業排名持續向下（數字變大）→ 產業轉弱

**應用**：
- 找出排名從後段躍升到前段的產業 → 可能是新的輪動方向
- 長期穩居前段的產業 → 持續性強勢產業

## Tab 4：供應鏈分析

**功能**：分析產業間的營收動能連動關係，發現領先/落後的供應鏈傳導效應。

**分析內容**：

| 分析項 | 說明 |
|--------|------|
| 營收動能傳導 | 上游產業營收動能是否領先下游 |

**應用場景**：
- 半導體上游營收加速 → 預判系統組裝跟進

## 產業輪動的概念

### 景氣循環與產業輪動

| 景氣階段 | 特徵 | 通常強勢產業 |
|----------|------|-------------|
| 復甦初期 | 利率低、信貸寬鬆 | 金融、不動產 |
| 擴張期 | 企業獲利改善 | 科技、可選消費 |
| 景氣高峰 | 通膨上升、需求旺盛 | 能源、原物料 |
| 衰退期 | 經濟放緩 | 必需消費、醫療 |

### 台灣產業特色

- 半導體是台股最重要的產業（佔大盤權重 30%+）
- 電子業受全球科技景氣影響大
- 傳產股受中國/東南亞需求影響
- 金融股受利率政策影響

### 兩層產業分類

## 模型改進

### 指數衰減加權

營收動能與法人流向的計算可啟用時間衰減加權，讓近期資料的影響力大於遠期。

**原理**：使用指數衰減函數 `weight = exp(-λ × Δt)`，其中 `λ = ln(2) / half_life`。

| 參數 | 衰減對象 | 單位 | 預設 |
|------|----------|------|------|
| `decay_half_life`（營收） | 月營收 YoY | 月 | None（不衰減） |
| `decay_half_life`（法人） | 法人淨買超 | 天 | None（不衰減） |

**效果**：
- 半衰期 = 2 個月 → 2 個月前的資料權重降為 50%，4 個月前降為 25%
- 半衰期 = 7 天 → 7 天前的法人資料權重降為 50%，14 天前降為 25%
- `decay_half_life=None` 時行為與原版完全一致（向後相容）

**適用場景**：市場快速輪動時期，開啟衰減可讓排名更敏感地反映近期變化。

### ICIR 動態權重調整

`industry_composite_score()` 新增 `dynamic_weights` 參數，允許根據歷史 IC（Information Coefficient）動態調整營收動能與法人流向的權重。

```python
dynamic_weights = {"momentum": 0.6, "flow": 0.4}
composite = industry_composite_score(momentum, flow, dynamic_weights=dynamic_weights)
```

可搭配 `analysis/utils/dynamic_weights.py` 的 IC 衰減權重計算，實現自適應權重。

## 供應鏈擴展

供應鏈分析從原本 4 條電子業鏈擴展為 13 條，覆蓋電子、傳產、金融外的主要產業鏈。

| 供應鏈 | 環節（上游→下游） |

| 面板供應鏈 | LED → TFT-LCD → 光通訊 |
| 通訊供應鏈 | 網路設備 → 電信設備 → 行動電話 |
| 消費電子供應鏈 | LED → 光通訊 → 消費性電子 → 行動電話 → 資訊通路 |
| 汽車供應鏈 | 汽車零件 → 整車 |
| 化學工業供應鏈 | 塑化原料 → 電子化學 → 特用化學 |
| 生技醫療供應鏈 | 原料藥/學名藥 → 新藥研發 → 醫材/醫療器材 → 醫美/保健 |
