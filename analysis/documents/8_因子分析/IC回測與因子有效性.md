# IC 回測與因子有效性

## 功能概述

驗證各因子的預測能力，透過 IC（Information Coefficient）回測量化因子與未來報酬的相關性。提供因子間相關性分析與有效性排行，協助投資人選擇最有效的因子組合。

## 操作介面

### Sidebar 設定

| 設定項 | 選項 | 說明 |
|--------|------|------|
| 股票池 | 成交量前 50 / 前 100 / 自選 | 分析的股票範圍 |
| 因子選擇 | 11 個因子（多選） | 要分析的因子 |
| 前瞻天數 | 5 / 10 / 20 | 計算未來報酬的天數 |
| 日期範圍 | 近 6 月 / 近 1 年 / 近 2 年 | 分析期間 |

## 可分析因子（11 個）

### 技術面因子（6 個）

| 因子 | 計算方式 | 預期方向 |
|------|---------|---------|
| RSI(14) | 14 日相對強弱指標 | 低 RSI → 未來上漲（反轉） |
| MACD Histogram | MACD(12,26,9) 柱狀圖 | 正值 → 趨勢向上 |
| MA20 方向 | 20 日均線斜率 | 正斜率 → 趨勢向上 |
| KD-K值 | 9 日 K 值 | 低 K 值 → 超賣反彈 |
| Bollinger %B | 在布林通道中的相對位置 | 低 %B → 超賣反彈 |
| 成交量比 | 當日量 / 20 日均量 | 放量 → 趨勢確認 |

### 基本面因子（3 個）

| 因子 | 計算方式 | 預期方向 |
|------|---------|---------|
| PER | 本益比 | 低 PER → 價值低估 |
| PBR | 股價淨值比 | 低 PBR → 價值低估 |
| 殖利率 | 現金殖利率 | 高殖利率 → 價值吸引 |

### 籌碼面因子（2 個）

| 因子 | 計算方式 | 預期方向 |
|------|---------|---------|
| 法人淨買超 | 三大法人合計淨買超 | 正值 → 法人看多 |
| 外資淨買超 | 外資淨買超 | 正值 → 外資看多 |

## Tab 1：IC 回測驗證

### IC 的定義

```
IC = Spearman_Rank_Correlation(因子值, 未來N天報酬率)
```

- IC > 0：因子值越大，未來報酬越高（正向因子）
- IC < 0：因子值越大，未來報酬越低（反向因子）
- |IC| 越大，因子預測能力越強

### 顯示指標

| 指標 | 公式 | 判斷標準 |
|------|------|---------|
| Mean IC | IC 序列的平均值 | > 0.03 為有效因子 |
| IC > 0 比率 | IC 為正的天數百分比 | > 55% 為穩定 |
| IC Std | IC 序列的標準差 | 越小越穩定 |
| ICIR | Mean IC / IC Std | > 0.5 為強因子 |

### 圖表

1. **IC 時間序列 Bar Chart**：每日 IC 值，正負以不同顏色區分
2. **累積 IC 折線圖**：IC 累加值，持續上升表示因子持續有效

## Tab 2：因子相關性矩陣

### 功能

計算所有選取因子之間的截面相關性，以熱力圖呈現。

### 共線性警告

當任兩因子相關性 > 0.7 時，系統顯示警告：
- 高共線性因子不應同時使用（資訊重複）
- 建議只保留其中 ICIR 較高的因子

### 常見高相關因子組

| 因子 A | 因子 B | 原因 |
|--------|--------|------|
| RSI | KD-K值 | 都是動量指標 |
| PER | PBR | 都是估值指標 |
| 法人淨買超 | 外資淨買超 | 外資佔法人主體 |

## Tab 3：因子有效性排行

### 排行表格

| 欄位 | 說明 |
|------|------|
| 因子名稱 | 因子標識 |
| 類型 | 技術面 / 基本面 / 籌碼面 |
| Mean IC | IC 均值 |
| IC > 0 比率 | IC 正值比率 |
| IC Std | IC 標準差 |
| ICIR | IC 資訊比率 |
| 有效性 | 強 / 中 / 弱 |

### 有效性判定標準

| 等級 | 條件 |
|------|------|
| 強 | ICIR > 0.5 且 Mean IC > 0.03 |
| 中 | ICIR > 0.3 或 Mean IC > 0.02 |
| 弱 | 其他 |

### 判讀說明

- **ICIR > 0.5**：因子預測穩定且有效，可作為策略核心因子
- **ICIR 0.3~0.5**：有一定預測力，可作為輔助因子
- **ICIR < 0.3**：預測力不穩定，不建議單獨使用
- **Mean IC 的正負號**：決定因子的使用方向（正向/反向）
