# 動態權重追蹤

## 功能概述

根據各因子的滾動 IC 表現，自動計算並追蹤因子權重的動態變化。解決傳統固定權重無法適應市場結構變化的問題，讓有效因子獲得更高權重，失效因子自動降權。

## 操作設定

| 設定項 | 選項 | 預設 | 說明 |
|--------|------|------|------|
| 權重計算方式 | ICIR 加權 / IC 均值加權 / IC 指數衰減 | ICIR 加權 | 三種動態權重方法 |
| 滾動窗口 | 20 ~ 120 天 | 60 | 計算滾動 IC 的窗口大小 |

## 三種權重計算方法

### 1. ICIR 加權（推薦）

```
IC_mean_i = Rolling_Mean(IC_i, window)
IC_std_i = Rolling_Std(IC_i, window)
ICIR_i = |IC_mean_i / IC_std_i|
weight_i = ICIR_i / Σ(ICIR_j)  （歸一化）
```

**特點**：
- 同時考慮因子的預測力（IC 均值）和穩定性（IC 標準差）
- 預測力強且穩定的因子獲得最高權重
- 波動大的因子即使平均 IC 高，權重也會被壓低

### 2. IC 均值加權

```
IC_mean_i = Rolling_Mean(|IC_i|, window)
weight_i = IC_mean_i / Σ(IC_mean_j)  （歸一化）
```

**特點**：
- 只考慮因子的平均預測力，不考慮穩定性
- 計算更簡單，但可能給波動大的因子過高權重
- 適合因子 IC 都比較穩定的情況

### 3. IC 指數衰減

```
time_weight(t) = exp(-λ × (T - t))    λ = ln(2) / half_life
weighted_IC_i = Σ(IC_i(t) × time_weight(t)) / Σ(time_weight(t))
weight_i = |weighted_IC_i| / Σ(|weighted_IC_j|)  （歸一化）
```

**特點**：
- 近期 IC 的影響力指數級大於遠期
- `half_life = window / 3`：例如 window=60 時，half_life=20
- 對市場結構變化反應最快
- 適合因子有效性快速輪換的市場

## 最低 IC 門檻

所有方法都套用最低 IC 門檻 `min_ic = 0.02`：
- 滾動 |IC| 低於 0.02 的因子，權重自動歸零
- 防止失效因子仍佔有權重
- 剩餘因子重新歸一化為 100%

## 視覺化

### 1. 各因子滾動 IC 趨勢折線圖

- 多條折線，每條代表一個因子的滾動 IC
- 可觀察哪些因子正在變強/變弱
- IC 持續下降的因子可能正在失效

### 2. 因子權重變化 Stacked Area Chart

- 堆疊面積圖，Y 軸 = 100%（所有因子權重之和）
- 可觀察權重如何隨時間重新分配
- 某因子面積急劇縮小 → 該因子正在失效
- 某因子面積急劇擴大 → 該因子正在變強

### 3. 當前最新權重配置表

| 欄位 | 說明 |
|------|------|
| 因子名稱 | 因子標識 |
| 當前權重 | 最新一期的權重（%） |
| 變化 | 與上期相比的權重變化 |

## 使用建議

### 滾動窗口選擇

| 窗口 | 特性 | 適用場景 |
|------|------|---------|
| 20~30 天 | 反應快，權重頻繁變動 | 短線因子、快速輪動市場 |
| 40~60 天 | 平衡型 | 一般使用（推薦） |
| 80~120 天 | 穩定型，權重變動慢 | 長線因子、穩定市場 |

### 方法選擇建議

| 方法 | 適用場景 |
|------|---------|
| ICIR 加權 | 通用推薦，穩定且全面 |
| IC 均值 | 因子 IC 本身穩定時使用 |
| 指數衰減 | 市場結構頻繁變化時使用 |

## 與多因子策略的整合

動態權重計算的結果可回饋到「多因子綜合策略」（MultiFactorStrategy）中：
- 傳統方式：固定 tech_weight=0.4, chip_weight=0.3, fund_weight=0.3
- 動態方式：根據最新 IC 表現自動調整三大面向的權重
- 在 8_因子分析頁面觀察到的最佳權重配置，可手動設定到策略參數中
