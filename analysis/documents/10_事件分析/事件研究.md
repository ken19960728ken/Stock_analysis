# 事件研究

## 功能概述

事件研究法（Event Study）是金融學中分析特定事件對股價影響的標準方法。本頁面支援除息事件與財報公布事件的異常報酬分析，計算 CAR（累積異常報酬）與 AAR（平均異常報酬）。

## 操作介面

### Sidebar 設定

| 設定項 | 選項 | 預設 | 說明 |
|--------|------|------|------|
| 事件類型 | 除息事件 / 財報公布 | 除息事件 | 分析的事件種類 |
| 股票池 | 成交量前 50 / 自選 | 前 50 | 分析的股票範圍 |
| 事件前窗口 | 1 ~ 30 天 | 10 | 事件前觀察天數 |
| 事件後窗口 | 1 ~ 60 天 | 20 | 事件後觀察天數 |
| 異常報酬模型 | 市場調整 / 均值回歸 | 市場調整 | 計算異常報酬的模型 |

## 核心概念

### 異常報酬（Abnormal Return）

```
AR(t) = R(t) - E[R(t)]
```

- R(t)：實際報酬率
- E[R(t)]：預期報酬率（依模型計算）
- AR(t) > 0：股價表現優於預期

### 異常報酬模型

#### 市場調整模型（Market Adjusted）

```
E[R(t)] = R_market(t)
AR(t) = R_stock(t) - R_market(t)
```

- 以全市場平均報酬作為預期報酬
- 假設：沒有事件的話，個股表現應與大盤一致
- 適合大型股

#### 均值回歸模型（Mean Return）

```
E[R(t)] = Mean(R_stock, 估計窗口)
AR(t) = R_stock(t) - Mean(R_stock)
```

- 以該股票歷史平均報酬作為預期報酬
- 估計窗口 = 事件前 120 個交易日
- 適合各類型股票

### AAR（Average Abnormal Return）

```
AAR(t) = (1/N) × Σ AR_i(t)
```

- N 個事件在同一相對日（t）的平均異常報酬
- 反映事件在特定時間點的平均影響

### CAR（Cumulative Abnormal Return）

```
CAR(t₁, t₂) = Σ AAR(t), t = t₁ to t₂
```

- AAR 的累積值
- 反映事件在整個窗口期間的總影響

## Tab 1：CAR/AAR 分析

### 統計卡片

| Metric | 說明 |
|--------|------|
| 事件數 | 分析的事件總數 |
| CAR | 事件窗口內的累積異常報酬 |
| AAR | 事件窗口內的平均日異常報酬 |
| AAR > 0 比率 | 日異常報酬為正的天數比例 |

### CAR 折線圖

- X 軸：相對事件日的天數（-10 ~ +20）
- Y 軸：累積異常報酬（%）
- 事件日（Day 0）以垂直虛線標示
- CAR 持續上升 → 事件有正面影響
- CAR 在事件前上升 → 可能有資訊提前反應

### AAR 柱狀圖

- X 軸：相對事件日的天數
- Y 軸：平均異常報酬（%）
- 正值（藍/綠）→ 該日平均表現優於預期
- 負值（紅）→ 該日平均表現劣於預期

## 事件類型說明

### 除息事件

- **資料來源**：`dividend_history` 表
- **事件日**：除息交易日
- **事件值**：現金股利金額
- **典型模式**：
  - 除息前 5~10 天：股價可能上漲（搶息行情）
  - 除息日：股價自然下跌（除息缺口）
  - 除息後 10~30 天：填息行情（CAR 是否回到 0 以上）

### 財報公布事件

- **資料來源**：`financial_reports` 表（EPS 類型）
- **事件日**：財報公布日期
- **事件值**：每股盈餘（EPS）
- **典型模式**：
  - 財報前：市場預期交易
  - 財報日：超預期則跳漲，低於預期則下跌
  - 財報後：趨勢延續或反轉
