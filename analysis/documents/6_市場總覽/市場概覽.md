# 市場概覽

## 功能概述

全市場鳥瞰圖，提供當日市場快照、漲跌分佈、法人動態排行、估值分佈、高殖利率排行等資訊，協助投資人快速掌握整體市場狀態。

## 分析模組

### 1. 市場快照

**4 個 Metric 卡片**：

| Metric | 說明 | 資料來源 |
|--------|------|---------|
| 上漲家數 | 當日收盤價 > 前日收盤價的股票數 | SQL 計算 |
| 下跌家數 | 當日收盤價 < 前日收盤價的股票數 | SQL 計算 |
| 法人淨買超 | 三大法人當日合計淨買超金額 | `chip_institutional` |
| 市場平均 P/E | 全市場本益比平均值 | `stock_per` |

**判讀**：
- 上漲 > 下跌 → 市場偏多
- 上漲 < 下跌 → 市場偏空
- 法人大量淨買超 → 市場有撐

### 2. 漲跌幅分佈

**圖表**：Histogram（全市場日漲跌幅分佈）

- X 軸：漲跌幅百分比
- Y 軸：股票數量
- 可觀察市場的偏態（是否偏多或偏空）

### 3. 法人動態排行

**兩個表格並排**：

| 表格 | 內容 | 排序 |
|------|------|------|
| Top 20 買超 | 法人淨買超金額最高的 20 檔 | 金額降冪 |
| Top 20 賣超 | 法人淨賣超金額最高的 20 檔 | 金額升冪 |

**判讀**：
- 大量買超的個股 → 法人積極佈局
- 買超集中在特定產業 → 可能是產業輪動訊號

### 4. 估值分佈

**兩個 Histogram 並排**：

| 圖表 | 說明 |
|------|------|
| P/E 分佈 | 全市場本益比分佈，觀察市場整體估值水位 |
| P/B 分佈 | 全市場股價淨值比分佈 |

**判讀**：
- P/E 中位數偏低 → 市場整體偏低估
- P/B < 1 的比例高 → 市場可能過度悲觀

### 5. 高殖利率排行

**表格**：Top 30 殖利率最高的股票

| 欄位 | 說明 |
|------|------|
| stock_id | 股票代碼 |
| name | 股票名稱 |
| dividend_yield | 現金殖利率（%） |
| per | 本益比 |
| pbr | 股價淨值比 |
| close | 最新收盤價 |

**判讀**：
- 殖利率 > 5% 且 P/E 合理 → 高息穩健股候選
- 殖利率異常高（> 10%）→ 需確認是否股價大跌導致

### 6. 產業熱力圖

**圖表**：產業 × 指標 熱力圖

以色彩矩陣呈現各產業在多個維度的表現：

| 維度 | 說明 |
|------|------|
| 漲跌幅 | 產業平均日漲跌幅 |
| 法人淨買超 | 產業法人合計淨買超 |
| 成交量變化 | 相對前期的量能變化 |

**判讀**：
- 深綠色 = 表現強勢
- 深紅色 = 表現弱勢
- 可快速辨識當日資金流向的產業偏好
