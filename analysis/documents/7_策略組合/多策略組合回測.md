# 多策略組合回測

## 功能概述

將多個策略組合在一起回測，分析策略間的相關性與互補效果。支援 4 種權重分配方式：等權分配、Sharpe 最大化、最小波動率、風險平價。目標是透過策略分散降低整體風險。

## 操作介面

### Sidebar 設定

| 設定項 | 說明 |
|--------|------|
| 策略選擇 | 多選（至少 2 個），從 22 個內建策略中選取 |
| 股票選擇 | 單一股票，用同一支股票測試不同策略的組合效果 |
| 開始/結束日期 | 回測期間 |
| 權重模式 | 等權分配 / Sharpe 最大化 / 最小波動率 / 風險平價 |

## 權重分配方式

### 1. 等權分配（Equal Weight）

```
每個策略權重 = 1 / N（N = 策略數量）
```

- 最簡單的方式，不需要歷史數據最佳化
- 適合策略間差異不大的情況

### 2. Sharpe 最大化（Max Sharpe）

```
最大化：(E[R_p] - R_f) / σ_p
約束條件：Σw = 1, w >= 0
```

- 使用 SLSQP 最佳化求解
- 找到風險調整報酬最高的權重組合
- 可能集中於少數高 Sharpe 策略
- 依賴歷史 Sharpe 估計，可能過擬合

### 3. 最小波動率（Min Volatility）

```
最小化：σ_p = √(w'Σw)
約束條件：Σw = 1, w >= 0
```

- 追求波動最小的組合
- 適合風險厭惡型投資人
- 會偏向低波動策略

### 4. 風險平價（Risk Parity）

```
目標：每個策略的風險貢獻相等
RC_i = w_i × (Σw)_i / σ_p = 1/N × σ_p
```

- 讓每個策略承擔相等的風險份額
- 低風險策略獲得更高權重，高風險策略降權
- 橋水基金 All Weather 策略的核心概念

## 分析結果

### 1. 策略績效對比表

| 欄位 | 說明 |
|------|------|
| 策略名稱 | 各策略名稱 |
| 總報酬率 | 策略單獨運行的總報酬 |
| 年化報酬 | 年化後報酬率 |
| Sharpe | Sharpe Ratio |
| Sortino | Sortino Ratio |
| 最大回撤 | 最大回撤幅度 |
| 勝率 | 獲利交易百分比 |
| 交易次數 | 完成的買賣來回次數 |

### 2. 策略報酬相關性矩陣

熱力圖（RdBu_r 色彩）顯示各策略日報酬的相關性：

| 相關性 | 意義 |
|--------|------|
| > 0.7 | 高度正相關，組合效果有限 |
| 0.3 ~ 0.7 | 中度相關，有分散效果 |
| < 0.3 | 低相關，優質分散組合 |
| < 0 | 負相關，最佳互補效果 |

**理想的策略組合**：選擇相關性低的策略（例如趨勢策略 + 反轉策略）。

### 3. 權益曲線疊圖

在同一張圖上顯示：
- 各策略的獨立權益曲線
- 組合策略的權益曲線（粗線）
- 可直觀比較組合是否比個別策略更穩定

### 4. 組合績效指標

| Metric | 說明 |
|--------|------|
| 組合總報酬率 | 加權後的組合總報酬 |
| 組合 Sharpe Ratio | 組合的風險調整報酬 |

### 5. 權重分配 Bar Chart

水平條形圖顯示各策略的最終權重分配。

### 6. 風險貢獻 Pie Chart

圓餅圖顯示各策略對組合總風險的貢獻比例：

```
風險貢獻_i = w_i × (Σw)_i / σ_p²
```

- 風險平價模式下，各策略的風險貢獻應趨近相等
- 若某策略風險貢獻過大（> 50%），表示組合過度依賴單一策略

## 使用建議

### 策略組合建議

| 組合類型 | 策略搭配 | 特性 |
|----------|---------|------|
| 趨勢 + 反轉 | MA 交叉 + RSI 反轉 | 不同市況互補 |
| 技術 + 基本面 | MACD + 價值投資 | 多維度確認 |
| 短線 + 長線 | Dual Thrust + MA(60/240) | 時間分散 |
| 全面型 | 多因子 + 法人跟單 + 自由現金流 | 三維度覆蓋 |
| 動量 + 基本面 | 量價動能 + 營收動能 | 量能確認 + 營收驗證 |
| 趨勢 + 波動 | 趨勢過濾MA + 波動率壓縮 | 順勢 + 突破互補 |
| 產業 + 籌碼 | 次產業輪動 + 法人跟單 | 產業配置 + 個股確認 |

### 注意事項

- 組合策略不一定比單一最佳策略的報酬更高，但通常回撤更小
- Sharpe 最大化可能過度集中，建議搭配觀察風險貢獻
- 建議至少選 3 個策略以達到有效分散
