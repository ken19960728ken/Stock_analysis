# 多維度條件選股

## 功能概述

提供四大維度（估值面、技術面、成長面、籌碼面）的條件篩選工具，可同時設定多個門檻值進行交叉過濾，快速從全市場中篩選出符合條件的標的。篩選結果支援自訂排序與 CSV 匯出。

## 篩選維度

### 估值面

| 篩選條件 | 控制項 | 預設值 | 說明 |
|----------|--------|--------|------|
| P/E 範圍 | 雙向 Slider | 5.0 ~ 30.0 | 本益比區間，排除極端值 |
| P/B 範圍 | 雙向 Slider | 0.0 ~ 5.0 | 股價淨值比區間 |
| 殖利率 >= | 單向 Slider | 0.0% | 最低現金殖利率門檻 |

**使用場景**：
- P/E 5~15 + 殖利率 >= 4% → 低估高息股篩選
- P/B < 1.0 → 股價低於帳面價值的潛力股

### 技術面

| 篩選條件 | 控制項 | 預設值 | 說明 |
|----------|--------|--------|------|
| 股價範圍 | 雙向 Slider | 10 ~ 2000 | 過濾低價股/高價股 |
| 最低成交量 | 數字輸入 | 0 | 日均成交量門檻（張） |

**使用場景**：
- 成交量 > 1000 張 → 確保流動性
- 股價 50~500 → 中價位股票池

### 成長面

| 篩選條件 | 控制項 | 預設值 | 說明 |
|----------|--------|--------|------|
| 月營收年增率 >= | 單向 Slider | -50.0% | 最新月營收 YoY 門檻 |

**使用場景**：
- YoY >= 20% → 高成長股篩選
- YoY >= 0% → 排除營收衰退標的

### 籌碼面

| 篩選條件 | 控制項 | 預設值 | 說明 |
|----------|--------|--------|------|
| 法人連買天數 >= | 數字輸入 | 0 | 三大法人連續買超天數 |
| 股東人數變化 <= | 單向 Slider | 30.0% | 最近 4 週股東人數變化（%） |

**使用場景**：
- 法人連買 >= 5 天 → 法人積極佈局
- 股東人數變化 <= -5% → 籌碼集中

### 商品類型

| 篩選條件 | 控制項 | 選項 |
|----------|--------|------|
| 商品類型 | 下拉選單 | 全部 / 上市 / 上櫃 |

## 篩選結果

### 結果表格欄位

| 欄位 | 說明 |
|------|------|
| `stock_id` | 股票代碼 |
| `name` | 股票名稱 |
| `type` | 上市/上櫃 |
| 收盤價 | 最新收盤價 |
| 成交量 | 最新成交量（張） |
| P/E | 本益比 |
| P/B | 股價淨值比 |
| 殖利率 | 現金殖利率（%） |
| 月營收 | 最新月營收（千元） |
| 法人買賣超 | 最新三大法人合計買賣超 |
| 月營收 YoY% | 月營收年增率 |
| 法人連買天數 | 三大法人連續買超天數 |
| 股東人數變化% | 最近 4 週股東人數變化比例 |

### 排序功能

- 可選擇任意欄位作為排序依據
- 支援升冪/降冪排序

### CSV 匯出

點擊匯出按鈕可下載篩選結果為 CSV 檔案。
