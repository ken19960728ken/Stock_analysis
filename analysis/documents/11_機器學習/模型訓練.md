# 模型訓練

## 功能概述

使用 LightGBM 梯度提升樹模型，對多因子進行非線性組合，預測個股未來 N 天報酬的分位等級。相比傳統的線性多因子模型，機器學習能捕捉因子之間的交互作用與非線性關係。

## 操作介面

### Sidebar 設定

| 設定項 | 選項 | 預設 | 說明 |
|--------|------|------|------|
| 股票池 | 成交量前 50 / 前 100 / 自選 | 前 50 | 訓練使用的股票範圍 |
| 前瞻天數 | 5 / 10 / 20 | 5 | 預測未來 N 天報酬 |
| 分位數 | 3 / 5 | 3 | 將報酬分為幾個等級 |
| 基本面因子 | 開啟/關閉 | 開啟 | 是否加入 PER/PBR/殖利率 |
| 籌碼面因子 | 開啟/關閉 | 開啟 | 是否加入法人買賣超 |
| 訓練資料範圍 | 近 1 年 / 近 2 年 / 近 3 年 | 近 2 年 | 訓練資料的時間長度 |

## 特徵工程

### 技術面特徵（必選，8 個）

| 特徵 | 計算方式 | 意義 |
|------|---------|------|
| `return_5d` | 5 日報酬率 | 短期動量 |
| `return_20d` | 20 日報酬率 | 中期動量 |
| `volatility_20d` | 20 日報酬標準差 | 波動風險 |
| `volume_ratio` | 當日量 / 20 日均量 | 量能變化 |
| `rsi` | RSI(14) | 超買超賣 |
| `macd_hist` | MACD Histogram | 趨勢動能 |
| `ma20_slope` | MA20 斜率 | 均線方向 |
| `bb_pct` | Bollinger %B | 通道位置 |

### 基本面特徵（選用，3 個）

| 特徵 | 計算方式 | 意義 |
|------|---------|------|
| `per` | 本益比 | 估值水位 |
| `pbr` | 股價淨值比 | 帳面價值比 |
| `dividend_yield` | 現金殖利率 | 股息吸引力 |

### 籌碼面特徵（選用，1 個）

| 特徵 | 計算方式 | 意義 |
|------|---------|------|
| `institutional_net` | 三大法人淨買超 | 法人動向 |

### 標籤（Y）

```
forward_return = 未來 N 天報酬率
label = pd.qcut(forward_return, n_quantiles, labels=False)
```

- 3 分位：0=差（後 1/3）, 1=中, 2=好（前 1/3）
- 5 分位：0=最差, 1, 2, 3, 4=最好

## 模型配置

### LightGBM 參數

| 參數 | 值 | 說明 |
|------|-----|------|
| objective | multiclass | 多分類任務 |
| num_class | n_quantiles | 分類數 |
| n_estimators | 500 | 最大樹數量 |
| learning_rate | 0.05 | 學習率 |
| max_depth | 6 | 樹最大深度 |
| num_leaves | 31 | 葉節點數 |
| min_child_samples | 20 | 葉節點最少樣本數 |
| early_stopping_rounds | 50 | 早停輪數 |
| verbose | -1 | 不輸出訓練日誌 |

### 交叉驗證

使用 **TimeSeriesSplit**（時序切割）而非隨機 K-Fold，避免前瞻偏差：

```
Split 1: Train [------] Val [--]
Split 2: Train [--------] Val [--]
Split 3: Train [----------] Val [--]
Split 4: Train [------------] Val [--]
Split 5: Train [--------------] Val [--]
```

- 預設 5 折
- 訓練集永遠在驗證集之前
- 確保不使用未來資料

## 訓練結果（Tab 1）

### 績效指標

| Metric | 說明 |
|--------|------|
| 訓練準確率 | 訓練集上的分類準確率 |
| 訓練 F1 | 訓練集上的加權 F1 Score |
| 驗證準確率 | 驗證集上的分類準確率 |
| 驗證 F1 | 驗證集上的加權 F1 Score |

**判讀**：
- 訓練準確率 >> 驗證準確率 → 過擬合
- 驗證準確率 > 40%（3分位）→ 優於隨機（33%）
- 驗證準確率 > 25%（5分位）→ 優於隨機（20%）

### 特徵重要性 Bar Chart

- 水平條形圖，以 Gain（分裂增益）衡量
- 排名越前的特徵對預測影響越大
- 可用來決定哪些因子最有效

### 混淆矩陣 Heatmap

- N × N 矩陣（N = 分位數）
- 對角線 = 正確預測數
- 對角線越亮 → 模型分類越準確
- 觀察模型是否特別擅長/不擅長某個分位

## 環境需求

```bash
# 需要安裝 lightgbm
uv add lightgbm

# macOS 需要額外安裝 libomp
brew install libomp
```

若未安裝 lightgbm，相關功能會自動跳過（graceful degradation）。
