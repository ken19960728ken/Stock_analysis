# 選股推薦

## 功能概述

使用已訓練好的 LightGBM 模型，對最新截面資料進行預測，輸出各股票的預測分位與推薦買賣方向。本功能在 Tab 2 中呈現。

## 前置條件

必須先在 Tab 1 完成模型訓練，取得有效的 LightGBM 模型後才能進行選股推薦。

## 預測流程

```
1. 取得股票池中所有股票的最新一期特徵值
2. 使用訓練好的模型進行預測
3. 輸出每支股票的預測機率分佈
4. 取機率最高的分位作為預測標籤
5. 計算 pred_score = 最高分位的機率值
6. 依 pred_score 降冪排序
```

## 推薦表格

### 排序表

| 欄位 | 說明 |
|------|------|
| 排名 | 依 pred_score 降冪 |
| stock_id | 股票代碼 |
| 預測分數 | pred_score（模型信心度，0~1） |
| 預測分位 | pred_label（0=差, 1=中, 2=好） |
| 推薦 | 買入 / 持有 / 賣出 |

### 推薦規則

| 預測分位 | 推薦 | 說明 |
|----------|------|------|
| 最高分位（2 或 4） | 買入 | 模型預測未來報酬在前 1/3 或 1/5 |
| 中間分位 | 持有 | 模型預測報酬中等 |
| 最低分位（0） | 賣出 | 模型預測未來報酬在後 1/3 或 1/5 |

### 摘要卡片

- **買入推薦**（綠色 success callout）：列出預測為最高分位的股票
- **賣出推薦**（紅色 error callout）：列出預測為最低分位的股票

## 使用注意事項

### 模型信心度

- `pred_score > 0.6` → 模型相對有把握
- `pred_score ≈ 0.33`（3 分位）→ 接近隨機，參考性低
- 建議只交易 pred_score 較高的標的

### 局限性

1. **歷史資料偏差**：模型基於歷史訓練，市場結構變化時可能失效
2. **過擬合風險**：若訓練集準確率遠高於驗證集，推薦可能不可靠
3. **特徵時效性**：基本面/籌碼面數據更新頻率較低，可能有滯後
4. **非即時訊號**：推薦基於最新收盤資料，不適合盤中交易

### 最佳實踐

- 搭配 Tab 1 的特徵重要性分析，了解模型決策依據
- 搭配 Tab 3 的 Walk-Forward 回測，驗證模型的真實績效
- 不建議完全依賴 ML 選股，應與基本面研究相互驗證
- 定期（每週/每月）重新訓練模型以適應市場變化
