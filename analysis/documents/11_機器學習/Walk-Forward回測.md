# Walk-Forward 回測

## 功能概述

Walk-Forward（滾動前進）回測是評估機器學習模型真實績效的金標準方法。不同於一次性訓練/驗證，Walk-Forward 模擬實際交易中「只用過去資料訓練、預測未來」的過程，完全避免前瞻偏差。

## 操作介面

| 設定項 | 範圍 | 預設 | 說明 |
|--------|------|------|------|
| 訓練窗口 | 60 ~ 500 天 | 252 | 每次訓練使用的資料天數 |
| 步進天數 | 5 ~ 60 天 | 20 | 每次前進的天數（預測窗口） |

## 回測流程

```
時間軸：[=== 訓練 ===][= 預測 =]
                          ↓ 前進 step 天
         [=== 訓練 ===][= 預測 =]
                             ↓ 前進 step 天
            [=== 訓練 ===][= 預測 =]
                                ↓ ...
```

### 詳細步驟

```python
for t in range(train_window, len(data), step):
    # 1. 取訓練資料（只用過去的資料）
    X_train = X[t - train_window : t]
    y_train = y[t - train_window : t]

    # 2. 訓練模型
    model = train_lightgbm(X_train, y_train)

    # 3. 預測未來 step 天
    X_pred = X[t : t + step]
    predictions = model.predict(X_pred)

    # 4. 記錄預測與實際結果
    results.append(predictions vs actuals)
```

### 核心原則

- **只用過去訓練**：訓練集永遠在預測集之前
- **滾動窗口**：每次前進 `step` 天，重新訓練模型
- **無前瞻**：預測時不使用任何未來資訊
- **模擬真實**：最接近實際交易的模型評估方式

## 參數說明

### 訓練窗口（train_window）

| 值 | 約等於 | 特性 |
|----|--------|------|
| 60 | 3 個月 | 快速適應，但訓練資料少，模型可能不穩定 |
| 126 | 半年 | 中短期，適合快速變化的市場 |
| 252 | 1 年 | 標準設定，平衡穩定性與適應性 |
| 500 | 2 年 | 長期穩定，但對市場變化反應慢 |

### 步進天數（step）

| 值 | 約等於 | 特性 |
|----|--------|------|
| 5 | 1 週 | 高頻重訓練，計算成本高，但適應性最好 |
| 20 | 1 個月 | 標準設定，平衡效率與頻率 |
| 60 | 1 季 | 低頻重訓練，效率高但適應慢 |

## 回測結果

### Walk-Forward 準確率

```
WF_Accuracy = 正確預測數 / 總預測數
```

- 與一次性驗證準確率比較，WF 準確率通常較低（更真實）
- 3 分位隨機基準 = 33.3%
- 5 分位隨機基準 = 20.0%
- WF 準確率 > 隨機基準 → 模型有預測力

### 預測分數 vs 實際分位分佈

**Histogram**：
- 按預測標籤分組，顯示每組的實際報酬分佈
- 理想情況：預測為「好」的組，實際報酬應明顯高於「差」的組
- 若各組分佈重疊嚴重 → 模型區分度不足

### 每日準確率追蹤折線圖

- X 軸：日期
- Y 軸：滾動準確率（%）
- 含水平虛線標示隨機基準（33% 或 20%）
- 可觀察模型在不同時期的表現：
  - 準確率持續高於基準 → 模型穩定有效
  - 準確率大幅下降 → 市場結構可能改變，需重新檢視

## 結果解讀

### 理想的 Walk-Forward 結果

| 指標 | 目標 |
|------|------|
| WF 準確率 | > 隨機基準 + 5% |
| 準確率穩定性 | 時序上無大幅下降 |
| 分位區分度 | 預測「好」vs「差」的實際報酬差異 > 2% |

### 常見問題

| 問題 | 可能原因 | 解決方案 |
|------|---------|---------|
| WF 準確率 ≈ 隨機 | 特徵預測力不足 | 增加/替換特徵 |
| 準確率遞減 | 市場結構改變 | 縮短訓練窗口 |
| 訓練 >> 驗證 | 過擬合 | 減少特徵數、增大正則化 |
| 計算太慢 | 步進太小或股票太多 | 增大 step 或減少股票池 |

## 與傳統回測的比較

| 項目 | 傳統回測 | Walk-Forward |
|------|---------|-------------|
| 訓練/測試切割 | 固定一次 | 滾動多次 |
| 前瞻偏差風險 | 中等 | 極低 |
| 計算成本 | 低 | 高（多次訓練） |
| 結果可靠度 | 中等 | 高 |
| 是否反映真實交易 | 部分 | 接近真實 |
