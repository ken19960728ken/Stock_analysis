# 報告瀏覽

## 功能概述

瀏覽系統產出的歷史報告檔案，支援 Markdown 渲染、CSV 表格顯示與檔案下載。報告來源包含每日選股報告、策略回測報告等。

## 操作介面

### 報告類型

| 類型 | 來源 | 格式 |
|------|------|------|
| 每日選股報告 | `scripts/daily_stock_picker.py` | Markdown (.md) |
| 策略回測報告 | `scripts/strategy_report.py` | Markdown (.md) + CSV |

### 功能

| 功能 | 說明 |
|------|------|
| 報告列表 | 按日期排序，顯示 `reports/` 目錄下的所有報告 |
| Markdown 渲染 | 將 .md 報告渲染為格式化頁面 |
| CSV 表格 | 將 .csv 資料以互動表格呈現 |
| 檔案下載 | 提供原始檔案下載按鈕 |

## 報告目錄

預設讀取 `reports/` 目錄，報告檔名格式：

| 格式 | 範例 |
|------|------|
| 每日選股 | `daily_pick_2026-03-14.md` |
| 策略回測 | `MA交叉_全市場_2026-03-14.md` |

## 資料來源

報告檔案存放於專案根目錄的 `reports/` 資料夾，由腳本自動產出。
