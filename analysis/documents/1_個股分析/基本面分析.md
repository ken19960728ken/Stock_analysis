# 基本面分析

## 功能概述

呈現個股的基本面財務資訊，包含 EPS 季度趨勢、月營收成長、P/E 歷史河流圖、以及股利歷史。協助投資人從獲利能力、營收趨勢、估值水位、股利政策四個面向評估個股價值。

## 分析項目

### 1. EPS 季度趨勢圖

**圖表類型**：Bar Chart（各季 EPS）

| 資料欄位 | 說明 |
|----------|------|
| `type` = `EarningsPerShare` | 每股盈餘 |
| `date` | 財報季度日期 |
| `value` | EPS 數值（元） |

**判讀要點**：
- EPS 逐季成長 → 獲利動能向上
- EPS 同期年增 → 基本面改善
- 單季 EPS 大幅衰退 → 需關注原因（是否為一次性）

### 2. 月營收趨勢圖

**圖表類型**：Bar Chart（月營收）+ Line Chart（年增率%）

| 資料欄位 | 說明 |
|----------|------|
| `revenue` | 當月合併營收（千元） |
| `revenue_yoy` | 月營收年增率（%，與去年同月比） |

**判讀要點**：
- 營收創新高 + 年增率為正 → 營運強勁
- 營收季節性：比較同期 YoY 比 MoM 更有意義
- 連續數月年增率為負 → 營運衰退訊號

### 3. P/E 歷史河流圖

**圖表類型**：Area Chart（P/E 時序）+ 水平參考線

| 參考線 | 說明 |
|--------|------|
| 均值 | P/E 歷史平均值 |
| +1σ | 均值 + 1 個標準差（偏貴區間上緣） |
| -1σ | 均值 - 1 個標準差（偏低區間下緣） |

**判讀要點**：
- P/E 在 -1σ 以下 → 歷史低估區，可能是買點
- P/E 在 +1σ 以上 → 歷史高估區，需謹慎
- P/E 突然大幅下降 → 可能是盈餘大增（正面）或股價大跌（負面）
- 不同產業的合理 P/E 範圍不同，需橫向比較同業

### 4. 股利歷史圖

**圖表類型**：Bar Chart（現金股利 + 股票股利）

| 資料欄位 | 說明 |
|----------|------|
| `CashEarningsDistribution` | 現金股利（盈餘分配） |
| `StockEarningsDistribution` | 股票股利（盈餘轉增資） |
| `CashStaticDistribution` | 現金股利（資本公積分配） |

**判讀要點**：
- 股利逐年穩定或成長 → 公司獲利穩健、股利政策佳
- 殖利率 = 現金股利 / 股價 × 100%
- 突然減少股利 → 獲利衰退或公司保留現金
- 台灣除息日前後的填息行情是常見交易策略

## 基本面關鍵指標

### 估值指標

| 指標 | 公式 | 說明 |
|------|------|------|
| P/E（本益比） | 股價 / EPS | 越低越便宜，但需考慮成長性 |
| P/B（股價淨值比） | 股價 / 每股淨值 | < 1 表示股價低於帳面價值 |
| 殖利率 | 現金股利 / 股價 × 100% | 台股平均約 3-4% |

### 獲利能力指標

| 指標 | 公式 | 說明 |
|------|------|------|
| 毛利率 | (營收 - 成本) / 營收 × 100% | 反映產品競爭力 |
| 營業利益率 | 營業利益 / 營收 × 100% | 反映本業經營效率 |
| 淨利率 | 稅後淨利 / 營收 × 100% | 反映整體獲利能力 |
| EPS | 稅後淨利 / 流通股數 | 每股獲利金額 |
