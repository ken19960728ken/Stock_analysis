# 技術分析

## 功能概述

提供個股的 K 線圖表與多種技術指標疊加分析，支援日K/週K/月K 三種頻率切換，以及一般 K 線與 Heikin-Ashi 兩種顯示模式。

## 操作介面

### Sidebar 設定

| 控制項 | 說明 |
|--------|------|
| 股票選擇 | 從 DB 中所有股票清單選擇（格式：`代號 名稱`） |
| K 線頻率 | 日K / 週K / 月K（影響資料來源表格） |
| 時間範圍 | 3M / 6M / 1Y / 3Y（回溯計算起始日） |

### 主圖設定

| 設定 | 選項 | 預設 |
|------|------|------|
| K 線類型 | 一般 K 線 / Heikin-Ashi | 一般 K 線 |
| 均線選擇 | 5, 10, 20, 60, 120, 240 日（多選） | 5, 20, 60 |
| Bollinger Bands | 開啟/關閉 | 關閉 |
| Parabolic SAR | 開啟/關閉 | 關閉 |

### 副圖指標

可同時選擇多個副圖指標，每個指標獨立呈現在 K 線圖下方：

| 指標 | 說明 |
|------|------|
| MACD | 快線(12) - 慢線(26) + 訊號線(9)，柱狀圖顯示 MACD Histogram |
| RSI | 14 日 RSI，含 30/70 超賣/超買參考線 |
| KD | 9 日 K 值 + 3 日 D 值 隨機指標 |
| 威廉 | 14 日 Williams %R |
| AO | Awesome Oscillator（5/34 日中價差） |

## 最新數據摘要

頁面頂部以 6 個 Metric 卡片顯示最新交易日的關鍵數據：

| Metric | 說明 |
|--------|------|
| 收盤價 | 最新收盤價，含漲跌幅 delta |
| 最高 | 當日最高價 |
| 最低 | 當日最低價 |
| 成交量 | 當日成交量（股） |
| RSI(14) | 最新 RSI 數值 |
| K/D | 最新 K 值 / D 值 |

## 圖表互動

- 所有圖表支援 Plotly 互動操作：縮放、平移、懸停資訊
- 買賣標記以三角形圖示在 K 線圖上（若有策略訊號時）
- 成交量以紅/綠柱狀圖呈現（漲紅跌綠）

## 技術指標計算公式

### SMA（簡單移動平均）
```
SMA(N) = (C₁ + C₂ + ... + Cₙ) / N
```

### EMA（指數移動平均）
```
EMA(N) = C × (2/(N+1)) + EMA_prev × (1 - 2/(N+1))
```

### MACD
```
MACD Line = EMA(12) - EMA(26)
Signal Line = EMA(MACD Line, 9)
Histogram = MACD Line - Signal Line
```

### RSI
```
RS = Average Gain(14) / Average Loss(14)  （Wilder Smoothing）
RSI = 100 - 100/(1 + RS)
```

### Bollinger Bands
```
中軌 = SMA(20)
上軌 = SMA(20) + 2 × Std(20)
下軌 = SMA(20) - 2 × Std(20)
%B = (Close - 下軌) / (上軌 - 下軌)
```

### Parabolic SAR
```
SAR(t+1) = SAR(t) + AF × (EP - SAR(t))
AF 初始 = 0.02，每次新高/新低 +0.02，最大 0.20
EP = 多頭期間最高價 / 空頭期間最低價
```

### Heikin-Ashi
```
HA_Close = (Open + High + Low + Close) / 4
HA_Open = (HA_Open_prev + HA_Close_prev) / 2
HA_High = max(High, HA_Open, HA_Close)
HA_Low = min(Low, HA_Open, HA_Close)
```
