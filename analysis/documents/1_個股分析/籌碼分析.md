# 籌碼分析

## 功能概述

呈現個股的籌碼面資訊，包含三大法人買賣超、融資融券餘額變化、借券賣出餘額、以及股權分散表。籌碼分析有助於判斷市場主力的動向與散戶行為。

## 分析項目

### 1. 三大法人買賣超

**圖表類型**：雙 Y 軸 — Bar Chart（買賣超張數）+ Line Chart（收盤價）

| 資料欄位 | 說明 |
|----------|------|
| `Foreign_Investor` | 外資買賣超（張） |
| `Investment_Trust` | 投信買賣超（張） |
| `Dealer_total` | 自營商買賣超（張） |
| `close` | 收盤價（右 Y 軸） |

**判讀要點**：
- 外資連續買超 + 股價上漲 → 主力做多訊號
- 投信連續買超 → 法人認同基本面
- 三大法人同步買超 → 強烈多方訊號
- 法人賣超但股價不跌 → 承接力道強

### 2. 融資融券

**圖表類型**：雙折線圖（融資餘額 vs 融券餘額）

| 資料欄位 | 說明 |
|----------|------|
| `margin_purchase_balance` | 融資餘額（張）— 散戶看多借錢買 |
| `short_sale_balance` | 融券餘額（張）— 看空借券賣出 |

**判讀要點**：
- 融資增加 + 股價上漲 → 散戶追多（需警戒） |
- 融資減少 + 股價上漲 → 籌碼沉澱（正面訊號）
- 融券增加 + 股價上漲 → 軋空行情可能
- 融資融券同步增加 → 多空分歧加大

### 3. 借券賣出餘額

**圖表類型**：Scatter + Line（折線圖）

| 資料欄位 | 說明 |
|----------|------|
| `short_sale_balance` | 借券賣出餘額（張） |

**判讀要點**：
- 借券餘額持續增加 → 外資或法人看空
- 借券餘額快速下降 → 空方回補，可能反彈

### 4. 股權分散表

**圖表類型**：DataFrame 表格（最近 20 筆）

| 資料欄位 | 說明 |
|----------|------|
| `HoldingSharesLevel` | 持股分級（1-999股, 1000-5000股...） |
| `people` | 該級距持股人數 |
| `percent` | 該級距持股比例（%） |

**判讀要點**：
- 大額持股比例增加 → 籌碼集中於大戶
- 小額持股人數增加 → 散戶進場
- 千張大戶持股持續增加 → 主力進貨訊號

## 籌碼面關鍵概念

### 融資融券制度

| 項目 | 融資 | 融券 |
|------|------|------|
| 方向 | 看多（借錢買股票） | 看空（借股票賣出） |
| 使用者 | 通常為散戶 | 通常為專業投資人 |
| 保證金 | 約 4 成 | 約 9 成 |
| 意義 | 餘額增加 = 散戶看多 | 餘額增加 = 看空力道 |

### 三大法人

| 法人 | 特性 |
|------|------|
| 外資 | 資金量最大，中長線佈局為主 |
| 投信 | 內資法人，重視基本面，季度調倉 |
| 自營商 | 自有資金操作，短線進出為主 |
