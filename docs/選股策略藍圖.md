## 1. 選股哲學總覽

### 1.1 五大分析面向

| 面向 | 核心問題 | 適用場景 |
|------|---------|---------|
| **基本面** | 這家公司值多少錢？ | 中長期價值投資、存股 |
| **技術面** | 現在是進場/出場的時機嗎？ | 波段操作、趨勢交易 |
| **籌碼面** | 大戶在做什麼？ | 短中期動能判斷、確認訊號 |
| **產業面** | 哪些產業正在輪動？ | 產業配置、輪動策略 |
| **消息面** | 有什麼催化劑？ | 事件驅動、題材操作 |

> **本系統聚焦前四者**（基本面、技術面、籌碼面、產業面），以可量化、可回測的數據為基礎。消息面因難以結構化，暫不納入自動化流程，但可作為人工決策的輔助參考。

### 1.2 選股流程

本系統支援兩種選股路徑，可依市場環境靈活切換：

**由上而下（Top-Down）**

```
總經環境判斷 → 產業輪動篩選 → 個股基本面過濾 → 技術面擇時 → 籌碼面確認
```

適用於趨勢明確的市場，先確認大方向再挑個股。分析平台的「市場總覽」頁面提供總經指標（FRED API）與全市場漲跌分佈，可作為第一道篩選。「產業輪動」頁面提供兩層產業排名（大類 + 次產業）與供應鏈分析。

**由下而上（Bottom-Up）**

```
因子篩選選股池 → 基本面打分 → 技術面訊號過濾 → 籌碼面驗證 → 風控配置
```

適用於結構性行情或個股 Alpha 顯著的環境。分析平台的「因子篩選」頁面（`analysis/pages/2_因子篩選.py`）提供 P/E、P/B、殖利率、價格、成交量等多維度過濾。

## 2. 基本面策略

> 對應模組：`analysis/strategies/value_investing.py`、`fundamental_ratio.py`、`free_cash_flow.py`、`revenue_momentum.py`

### 2.1 財報三率分析

利用 `financial_reports` 表的長格式資料（`type` + `value`），計算關鍵獲利比率：

| 指標 | 計算方式 | 選股邏輯 |
|------|---------|---------|
| **毛利率** | `GrossProfit / Revenue` | 衡量產品競爭力，毛利率穩定 > 30% 為佳 |
| **營業利益率** | `OperatingIncome / Revenue` | 衡量本業經營效率，排除業外干擾 |
| **淨利率** | `NetIncome / Revenue` | 衡量最終獲利能力 |
| **EPS** | 直接取 `EarningsPerShare` | 每股盈餘，最直觀的獲利指標 |

**策略規則**（`FundamentalRatioStrategy`）：

- 毛利率連續 4 季 > 25%（排除低毛利代工業除外）
- 營業利益率 > 10%，且趨勢向上
- EPS 年增率 > 0%（成長型篩選）

### 2.2 成長指標

結合 `month_revenue`（月營收）與 `financial_reports`（季報），追蹤成長動能：

| 指標 | 資料來源 | 欄位 |
|------|---------|------|
| **月營收年增率** | `month_revenue` | `month_revenue_year_on_year` |
| **月營收金額** | `month_revenue` | `revenue` |
| **EPS 季增率** | `financial_reports` | `EarningsPerShare` 逐季比較 |
| **營收季增率** | `financial_reports` | `Revenue` 逐季比較 |

**策略規則**：

- 月營收 YoY > 10%，連續 3 個月
- EPS 連續 2 季正成長
- 營運現金流（`CashFlowsFromOperatingActivities`）為正

### 2.3 估值篩選

利用 `stock_per` 表進行估值過濾：

| 指標 | 欄位 | 選股條件 |
|------|------|---------|
| **本益比 P/E** | `per` | 5 ≤ P/E ≤ 15（低估值區間） |
| **股價淨值比 P/B** | `pbr` | P/B ≤ 2.0（資產折價保護） |
| **殖利率** | `dividend_yield` | ≥ 4%（高息存股） |

結合 `dividend_history` 表驗證股利穩定度：

- 近 5 年皆有配息
- 配息金額無大幅衰退（年減幅 < 20%）

### 2.4 現有策略模板

#### 價值投資（`ValueInvestingStrategy`）

```
參數：
  - pe_threshold: 15        （P/E 上限）
  - dividend_yield_threshold: 3.0  （殖利率下限 %）
  - revenue_growth_threshold: 0    （營收成長下限 %）

買入條件：P/E < 15 且殖利率 > 3% 且營收正成長
賣出條件：任一條件不再滿足
```

#### 自由現金流（`FreeCashFlowStrategy`）

```
參數：
  - fcf_yield_threshold: 5.0  （FCF Yield 下限 %）

買入條件：OCF > 0 且 FCF Yield ≥ 5%
賣出條件：OCF 轉負 或 FCF Yield 大幅衰退
```

#### 營收動能（`RevenueMomentumStrategy`）

```
參數：
  - yoy_threshold: 10.0     （月營收 YoY 加速門檻 %）
  - revenue_new_high: True   （是否要求營收創歷史新高）

買入條件：月營收 YoY 加速 + 營收創 12 個月新高
賣出條件：營收動能減速 或 YoY 轉負
```

### 2.5 進階延伸方向

| 策略概念 | 說明 | 所需資料 |
|---------|------|---------|
| **葛拉漢防禦型** | P/E < 15、P/B < 1.5、負債比 < 50% | `stock_per` + `financial_reports` |
| **股利成長策略** | 連續 N 年股利成長 + 殖利率 > 市場平均 | `dividend_history` + `stock_per` |

## 3. 技術面策略

> 對應模組：`analysis/utils/indicators.py`（16 個指標函數）+ `analysis/strategies/`（10 個技術面策略）

### 3.1 指標總覽

本系統在 `indicators.py` 中實作了 16 個純 pandas/numpy 技術指標，分為四大類：

#### 趨勢類

| 指標 | 函數 | 用途 |
|------|------|------|
| SMA（簡單移動平均） | `add_ma(df, periods=[5,20,60])` | 判斷趨勢方向，多頭/空頭排列 |
| EMA（指數移動平均） | `add_ema(df, periods=[5,20,60])` | 趨勢跟蹤，對近期價格更敏感 |
| MACD | `add_macd(df, fast=12, slow=26, signal=9)` | 趨勢轉折，柱狀圖翻正/負 |
| Parabolic SAR | `add_parabolic_sar(df, af=0.02, max_af=0.2)` | 停利停損追蹤，SAR 翻轉為訊號 |
| Heikin-Ashi | `add_heikin_ashi(df)` | 平滑 K 線，過濾假訊號 |

#### 動量類

| 指標 | 函數 | 用途 |
|------|------|------|
| RSI | `add_rsi(df, period=14)` | 超買（>70）/ 超賣（<30）判斷 |
| KD 隨機指標 | `add_kd(df, k_period=9, d_period=3)` | 短線超買超賣 + 黃金/死亡交叉 |
| Williams %R | `add_williams_r(df, period=14)` | 類似 RSI，-80 以下超賣、-20 以上超買 |
| Awesome Oscillator | `add_awesome_oscillator(df, fast=5, slow=34)` | 動量震盪器，確認趨勢力道 |

#### 波動度類

| 指標 | 函數 | 用途 |
|------|------|------|
| Bollinger Bands | `add_bollinger(df, period=20, std_dev=2.0)` | 波動率通道（含 bandwidth、%B） |
| Keltner Channel | `add_keltner(df, period=20, atr_mult=1.5)` | ATR 波動通道，與 BB 搭配判斷 Squeeze |
| ATR | `add_atr(df, period=14)` | 真實波動幅度，用於停損設定 |

#### 量能類

| 指標 | 函數 | 用途 |
|------|------|------|
| OBV | `add_obv(df, ema_period=14)` | 能量潮（含 OBV_EMA），判斷資金流向 |

> `compute_all_indicators(df)` 可一次計算所有常用指標。

### 3.2 趨勢策略

#### MA 交叉策略（`MACrossStrategy`）

```
買入：短期均線（5日）上穿長期均線（20日）— 黃金交叉
賣出：短期均線下穿長期均線 — 死亡交叉
參數：fast_period=5, slow_period=20
```

- 優勢：邏輯簡單、趨勢行情表現佳
- 弱勢：盤整期間頻繁假訊號
- 改進方向：加入成交量濾網、ATR 過濾

#### MACD 訊號策略（`MACDStrategy`）

```
買入：MACD 柱狀圖由負轉正（Histogram > 0）
賣出：MACD 柱狀圖由正轉負（Histogram < 0）
參數：fast=12, slow=26, signal=9
```

- 優勢：比 MA 交叉更平滑，能捕捉中期趨勢
- 弱勢：訊號延遲，錯過初始波段
- 改進方向：結合 MACD 背離判斷

#### Parabolic SAR 策略（`ParabolicSARStrategy`）

```
買入：SAR 由上方翻到下方（翻多）
賣出：SAR 由下方翻到上方（翻空）
參數：af=0.02, max_af=0.2
```

- 優勢：內建加速因子，趨勢越強追蹤越緊
- 弱勢：盤整期反覆翻轉
- 改進方向：搭配 ADX 趨勢強度濾網

#### Heikin-Ashi 策略（`HeikinAshiStrategy`）

```
買入：HA K 線由陰轉陽，且連續 N 根確認
賣出：HA K 線由陽轉陰，且連續 N 根確認
參數：confirm_bars=2
```

- 優勢：平滑 K 線大幅減少雜訊
- 弱勢：確認機制導致進出場延遲
- 改進方向：降低 confirm_bars 搭配其他指標交叉驗證

#### 趨勢過濾MA 策略（`TrendFilteredMAStrategy`）

```
買入：短期均線上穿長期均線 + 股價在 MA200 之上（多頭趨勢）+ 回檔反彈確認
賣出：短期均線下穿長期均線 或 跌破 MA200
參數：fast_period=5, slow_period=20, trend_period=200
```

- 優勢：大趨勢過濾 + 回檔進場，減少盤整期假訊號
- 弱勢：空頭市場完全不進場，可能錯過反轉
- 改進方向：結合 ADX 判斷趨勢強度

### 3.3 動量策略

#### RSI 反轉策略（`RSIReversalStrategy`）

```
買入：RSI < 30（超賣區反彈）
賣出：RSI > 70（超買區回落）
參數：period=14, oversold=30, overbought=70
```

- 優勢：反轉訊號明確，適合區間震盪
- 弱勢：強趨勢中 RSI 可長期處於極端值
- 改進方向：結合均線方向，順勢交易時僅取超賣買入

#### 量價動能策略（`VolumePriceMomentumStrategy`）

```
買入：成交量放大突破（量 > N 日均量 × 倍數）+ OBV 上升趨勢
賣出：量縮價跌 或 OBV 轉弱
參數：volume_mult=1.5, obv_ema_period=14
```

- 優勢：量價齊揚確認，訊號可靠性高
- 弱勢：量能不足時長期無訊號
- 改進方向：結合價格型態識別

### 3.4 波動度策略

#### Bollinger Bands 突破策略（`BollingerStrategy`）

```
買入：價格觸及下軌（BB_lower）
賣出：價格觸及上軌（BB_upper）
參數：period=20, std_dev=2.0
```

- 優勢：結合均值回歸與波動率
- 弱勢：突破後可能持續走勢（趨勢 vs 回歸）
- 改進方向：加入 BB_bandwidth 收斂/擴張判斷

#### Dual Thrust 策略（`DualThrustStrategy`）

```
買入：價格突破上軌（前 N 日高低點計算）
賣出：價格跌破下軌
參數：lookback=5, k1=0.5, k2=0.5
```

- 優勢：日內/短波段經典策略，適應性強
- 弱勢：參數敏感度高
- 改進方向：依波動率動態調整 k1/k2

#### 波動率壓縮突破策略（`VolatilitySqueezeStrategy`）

```
買入：Bollinger Bands 收縮至 Keltner Channel 之內（Squeeze 狀態）後向上突破
賣出：反向突破 或 Squeeze 再次觸發
參數：bb_period=20, bb_std=2.0, kc_period=20, kc_mult=1.5
```

- 優勢：精準捕捉低波動後的突破行情
- 弱勢：Squeeze 持續時間可能很長，等待成本高
- 改進方向：結合成交量確認突破有效性

### 3.5 技術面策略對照表

| 策略 | 類型 | 使用指標 | 適用行情 | 交易頻率 |
|------|------|---------|---------|---------|
| MA 交叉 | 趨勢 | SMA | 單邊趨勢 | 低 |
| MACD 訊號 | 趨勢 | MACD | 中期趨勢 | 低 |
| RSI 反轉 | 動量 | RSI | 區間震盪 | 中 |
| Bollinger 突破 | 波動度 | Bollinger Bands | 震盪轉趨勢 | 中 |
| Dual Thrust | 波動度 | High/Low Range | 短波段突破 | 高 |
| Parabolic SAR | 趨勢 | SAR | 單邊趨勢 | 低 |

## 4. 籌碼面策略

> 對應模組：`analysis/strategies/institutional.py`、`margin_signal.py`、`ownership_concentration.py` + 6 張 chip 表

### 4.1 法人動向分析

資料來源：`chip_institutional` 表

| 欄位 | 說明 |
|------|------|
| `foreign_investors_buy / sell` | 外資（含外資及陸資）買賣金額 |
| `investment_trust_buy / sell` | 投信買賣金額 |
| `dealer_buy / sell` | 自營商（含自行買賣 + 避險）買賣金額 |

**策略邏輯**：

```
法人跟單策略（InstitutionalStrategy）
買入：法人淨買超連續 N 日（consecutive_days=3）
賣出：法人淨賣超連續 N 日
```

**進階法人策略方向**：

| 策略 | 邏輯 | 說明 |
|------|------|------|
| **外資認養股** | 外資連買 > 5 日 且 買超金額遞增 | 外資持續加碼，股價上漲機率高 |
| **投信作帳** | 投信月底前連續買超 | 季底/年底投信績效作帳行情 |
| **三大法人共買** | 外資 + 投信 + 自營同日淨買超 | 共識性最強的多方訊號 |
| **法人背離** | 外資大買 但 投信大賣（或反向） | 觀察分歧後的收斂方向 |

### 4.2 融資融券分析

資料來源：`chip_margin` 表

| 欄位 | 說明 |
|------|------|
| `margin_purchase_balance` | 融資餘額（散戶多方力道） |
| `short_sale_balance` | 融券餘額（散戶空方力道） |

**策略邏輯**（`MarginSignalStrategy`）：

| 策略 | 邏輯 | 說明 |
|------|------|------|
| **融資減 + 股價漲** | 融資餘額下降且股價上漲 | 籌碼從散戶轉向大戶（籌碼沉澱） |
| **融券回補行情** | 融券餘額快速下降 | 空頭被迫回補，推升股價 |
| **券資比異常** | 融券 / 融資 > 30% | 軋空潛力股 |
| **融資斷頭風險** | 融資大增 + 股價下跌 | 散戶追高套牢，反向指標 |

### 4.3 股權集中度分析

資料來源：`chip_shareholding` 表

| 欄位 | 說明 |
|------|------|
| `shareholding_range` | 持股級距（如 "1000001~5000000"） |
| `shareholder_count` | 各級距股東人數 |
| `holding_percentage` | 各級距持股比例 |

**策略邏輯**（`OwnershipConcentrationStrategy`）：

| 策略 | 邏輯 | 說明 |
|------|------|------|
| **大戶持股增加** | 高持股級距（>1000 張）比例上升 | 主力持續布局 |
| **散戶出清** | 低持股級距股東人數下降 | 浮額減少，股價易漲 |
| **股東人數驟減** | 總股東人數周減 > 5% | 籌碼快速集中，關注後續走勢 |

### 4.4 其他籌碼資料

| DB 表 | 內容 | 策略應用 |
|-------|------|---------|
| `chip_holding_pct` | 各類法人持股比例 | 追蹤外資/投信持股變化趨勢 |
| `chip_securities_lending` | 借券資料 | 機構放空意圖判斷 |
| `chip_short_sale` | 借券賣出餘額 | 借券賣出增加 → 機構看空訊號 |

### 4.5 籌碼面策略組合建議

```
強勢籌碼訊號 = 法人連續買超
              + 融資餘額未大增（非散戶追價）
              + 大戶持股比例上升
              + 借券賣出餘額未增加

弱勢籌碼警訊 = 法人連續賣超
              + 融資餘額快速增加
              + 散戶股東人數增加
              + 借券賣出餘額上升
```

## 5. 多因子綜合策略

> 對應模組：`analysis/strategies/multi_factor.py`、`adaptive_ensemble.py`、`ml_factor.py`

### 5.1 多因子模型（`MultiFactorStrategy`）

```
描述：綜合技術面 (RSI/MACD)、籌碼面 (法人)、基本面 (PER) 加權評分

參數：
  - tech_weight:  0.4    （技術面權重）
  - chip_weight:  0.3    （籌碼面權重）
  - fund_weight:  0.3    （基本面權重）
  - buy_threshold:  0.6  （買入門檻分數）
  - sell_threshold: -0.3 （賣出門檻分數）
```

### 5.2 因子評分細節

#### 技術面評分（權重 40%）

| 因子 | 計算 | 分數範圍 |
|------|------|---------|
| RSI 訊號 | RSI < 30 → +1；RSI > 70 → -1 | [-1, +1] |
| MACD 訊號 | Histogram > 0 → +1；< 0 → -1 | [-1, +1] |

綜合技術分數 = (RSI 分數 + MACD 分數) / 2

#### 籌碼面評分（權重 30%）

| 因子 | 計算 | 分數範圍 |
|------|------|---------|
| 法人淨買賣超 | 淨買超 > 0 → +1；< 0 → -1 | [-1, +1] |

#### 基本面評分（權重 30%）

| 因子 | 計算 | 分數範圍 |
|------|------|---------|
| PER 估值 | PER < 15 → +1；PER > 30 → -1 | [-1, +1] |

### 5.3 最終分數計算

```
總分 = tech_weight × 技術分數 + chip_weight × 籌碼分數 + fund_weight × 基本面分數

買入條件：總分 ≥ buy_threshold  (0.6)
賣出條件：總分 ≤ sell_threshold (-0.3)
其他：    持有不動
```

### 5.4 多策略動態組合（`AdaptiveEnsembleStrategy`）

```
描述：同時執行多個子策略，依近期表現動態調整權重

機制：
  - 子策略包含 MA 交叉、RSI 反轉、法人跟單等
  - 每期計算各子策略近 N 日的 Sharpe Ratio
  - 依 Sharpe Ratio 正規化為權重
  - 加權合成最終訊號

優勢：自動適應市場環境，趨勢/震盪切換時權重自動調整
```

### 5.5 機器學習選股（`MLFactorStrategy`）

```
描述：LightGBM 多因子非線性組合預測

特徵工程：技術指標 + 籌碼指標 + 基本面指標 → 200+ 特徵
標籤：未來 N 日報酬率是否 > 0
訓練方式：Walk-Forward（滾動訓練 + 外樣本測試）
輸出：預測機率 > 閾值 → 買入訊號

分析平台頁面：11_機器學習.py
提供特徵重要性排序、學習曲線、績效報告
```

### 5.6 進階多因子方向

| 維度 | 候選因子 | 來源 |
|------|---------|------|
| **價值** | P/E、P/B、殖利率、EV/EBITDA | `stock_per`, `financial_reports` |
| **成長** | 月營收 YoY、EPS QoQ、毛利率趨勢 | `month_revenue`, `financial_reports` |
| **動量** | 近 20/60 日報酬率、RSI、MACD 方向 | `daily_price` |
| **品質** | ROE、營業利益率、現金流/淨利比 | `financial_reports` |
| **籌碼** | 法人買超天數、融資變化率、股權集中度變化 | 6 張 chip 表 |
| **規模** | 市值排序、成交量排序 | `market_value`, `daily_price` |

**進階評分機制**：

1. 各因子標準化（Z-Score 或百分位排序）
2. 因子間相關性檢查（去除高度共線因子）
3. IC（Information Coefficient）回測驗證因子有效性
4. 動態權重調整（依近期因子表現加減權）

### 6.1 產業輪動模型

本系統支援兩層產業分類：

| 層級 | 來源 | 說明 |
|------|------|------|
| **大類（sector）** | TWSE 產業分類 | 31 個大產業（半導體、金融、生技等） |
| **次產業（sub_industry）** | HiStock 細分類 | 110+ 個次產業（IC 設計、被動元件、DRAM 等） |

資料來源：`industry_classification` 表 + `data/sub_industry_mapping.json`

**排名指標**：

| 指標 | 預設權重 | 計算 |
|------|---------|------|
| 營收動能 | 50% | 產業內股票月營收 YoY 加權平均（支援指數衰減） |
| 法人流向 | 50% | 產業內法人淨買超合計（支援指數衰減） |

**模型增強**：

| 功能 | 說明 |
|------|------|
| **指數衰減加權** | `weight(t) = exp(-ln(2)/half_life × Δt)`，近期資料權重更高。營收半衰期預設 2 個月，法人半衰期預設 7 天 |
| **ICIR 動態權重** | 根據因子得分離散度自動調整營收/法人權重，取代手動 50/50 設定 |

### 6.2 次產業輪動策略（`SubIndustryRotationStrategy`）

```
描述：買入營收動能 + 法人流向排名靠前的次產業龍頭股

參數：
  - top_n_industries: 3      （選取前 N 個強勢次產業）
  - max_holding_days: 20     （最大持有天數）
  - rebalance_days: 5        （再平衡間隔）

買入條件：股票所屬次產業排名前 N 且為該次產業龍頭
賣出條件：次產業排名跌出前 N 或持有超過 max_holding_days
```

### 6.3 供應鏈分析（13 條）

`analysis/utils/supply_chain.py` 提供產業間連動分析：

| 功能 | 說明 |
|------|------|
| 營收動能傳導 | 上游產業營收動能 → 下游產業的領先/落後關係 |
| 領先落後矩陣 | 交叉相關分析（±6 月 lag），正值 = 行領先列 |
| 供應鏈熱力圖 | 視覺化產業間連動強度 |

**13 條供應鏈**：

| 類別 | 供應鏈 | 環節數 |
|------|--------|-------|
| 電子業 | 半導體、電子組裝、面板、通訊 | 5/8/3/3 |
| 消費電子 | 消費電子 | 5 |
| 傳統產業 | 汽車、化學工業、生技醫療、鋼鐵、食品、航運、建築、紡織 | 2/3/4/3/3/3/2/2 |

**應用場景**：
- 上游半導體營收加速 → 預判下游系統組裝跟進
- 電子零組件領先指標 → 提前佈局終端應用產業
- 傳產供應鏈（鋼鐵→特殊鋼、化學→電子化學）景氣傳導追蹤

## 7. 風控與資金管理

> 對應模組：`analysis/utils/risk.py`（11 個風控指標）+ `analysis/utils/backtester.py`

### 7.1 風險指標總覽

| 指標 | 函數 | 說明 |
|------|------|------|
| **VaR** | `calc_var(returns, confidence=0.95)` | 95% 信心水準下的最大損失 |
| **CVaR** | `calc_cvar(returns, confidence=0.95)` | 尾部風險（超過 VaR 的平均損失） |
| **Sharpe Ratio** | `calc_sharpe(returns, rf=0.015)` | 每單位風險的超額報酬（年化） |
| **Sortino Ratio** | `calc_sortino(returns, rf=0.015)` | 只懲罰下行風險的 Sharpe 變體 |
| **Beta** | `calc_beta(stock_returns, market_returns)` | 相對大盤的系統性風險 |
| **Alpha** | `calc_alpha(stock_returns, market_returns, rf=0.015)` | Jensen's Alpha，超額報酬（年化） |
| **最大回撤** | `calc_max_drawdown(equity)` | 歷史最大虧損幅度 + 持續天數 |
| **組合波動率** | `calc_portfolio_volatility(weights, cov_matrix)` | 投資組合整體波動 |
| **Information Ratio** | `calc_information_ratio(stock_returns, benchmark)` | 相對基準的超額報酬 / 追蹤誤差 |
| **Calmar Ratio** | `calc_calmar_ratio(annual_return, max_drawdown)` | 年化報酬 / 最大回撤 |
| **持倉風險報告** | `portfolio_risk_report(holdings, price_data, market)` | 綜合報告（VaR, CVaR, Sharpe, Beta, Alpha, 相關性矩陣） |

### 7.2 回測費用結構

回測引擎（`Backtester`）已內建台灣市場的真實交易成本：

| 項目 | 比率 | 說明 |
|------|------|------|
| 手續費 | 0.1425% | 買賣皆收，券商公定（可打折） |
| 證交稅 | 0.3% | 僅賣出時收取 |
| 滑價 | 0.1% | 模擬市價單成交偏差 |
| 交易單位 | 1000 股/張 | 台灣整張交易制度 |
| 預設資金 | 100 萬 | 可自訂 |

> 單趟來回成本約 **0.585%**（0.1425% × 2 + 0.3%），年化需交易報酬 > 7% 才能覆蓋月均一次交易的成本。

### 7.3 部位控制原則

| 規則 | 說明 |
|------|------|
| **單檔上限** | 單一個股不超過總資金 20% |
| **產業上限** | 同產業不超過總資金 40% |
| **最大持股數** | 5-15 檔（依資金規模） |
| **停損線** | 個股 -8% ~ -10%（可用 ATR 動態調整） |
| **停利線** | 依策略設定（趨勢策略用追蹤停利） |
| **VaR 限制** | 組合日 VaR(95%) 不超過總資金 2% |

### 7.4 風控檢查清單

進場前檢查：

- [ ] 單檔部位是否超過上限？
- [ ] 同產業曝險是否過度集中？
- [ ] 組合 VaR 是否在可承受範圍？
- [ ] 是否設定停損價位？
- [ ] 流動性是否足夠（日均量 > 500 張）？

持有期間監控：

- [ ] 最大回撤是否觸及警戒線（-15%）？
- [ ] Beta 是否過高（> 1.5）？
- [ ] Sharpe Ratio 是否持續為正？
- [ ] 相關性矩陣是否出現異常聚集？

### Phase 3.7：策略深度優化（華爾街審視）

> 以下方向來自對 Phase 1-3 已完成功能的深度審視，以「能否真正在實盤賺錢」為唯一標準。

#### 3.7a 回測系統重構 — 從玩具到武器（最優先）

**問題診斷**：目前回測引擎是「單股票、單策略、全資金」模型，這在華爾街是大忌 — 沒有任何基金經理會把 100% 資金押單檔。回測績效數字因此嚴重失真，無法作為實盤決策依據。

- [x] **前視偏差修正（Look-Ahead Bias Fix）**：修正 7 個策略的資料公布延遲（月營收 +10 天、季報 +45 天），修正 zscore 全期統計量偏差，回測引擎加入資料延遲模型
- [ ] **Universe-Level 回測框架**：每期對全市場打分 → 排名 → 選前 N 檔 → 等權/最佳化分配 → 整體組合績效。這才是機構級回測的基本形態
- [ ] **換手率與交易成本真實化**：記錄每期換倉（進出哪些股票），計算換手率。高換手策略在實際中被成本侵蝕的程度遠超想像
- [ ] **存活偏差修正（Survivorship Bias）**：目前只回測「現在還在上市」的股票，忽略已下市的。這會高估策略績效 1-3% / 年
- [ ] **基準比較標準化**：每份回測報告強制附上同期 0050 的 Buy & Hold 績效，包含 Alpha、Beta、Information Ratio、Tracking Error

**學理依據**：Harvey, Liu & Zhu (2016) "...and the Cross-Section of Expected Returns" — 回測中的多重比較問題；Bailey & López de Prado (2014) "The Deflated Sharpe Ratio" — 考慮多次回測的 Sharpe 膨脹

#### 3.7b 策略體質診斷與淘汰機制

**問題診斷**：22 個策略數量看似豐富，但品質參差不齊。華爾街的原則是「寧可 5 個強策略，不要 20 個弱策略」。弱策略在多策略投票中反而是噪音。

- [ ] **策略健康報告卡**：對每個策略自動生成標準化診斷 — Sharpe（扣除交易成本後）、Calmar、最大連續虧損次數、年化換手率、訊號頻率、平均持有天數、多空分佈
- [ ] **策略相關性矩陣**：計算 22 個策略的訊號相關性。高度相關的策略（> 0.7）只保留最強的一個，其餘降權或淘汰
- [ ] **市場環境分類器**：用 VIX 等價物（台灣加權指數波動率）+ 趨勢指標（MA50 vs MA200）將歷史分為「趨勢上漲 / 趨勢下跌 / 盤整」三種 regime，然後看每個策略在哪種環境下表現最好
- [ ] **策略衰退偵測**：滾動 12 個月 Sharpe Ratio，當 Sharpe 低於 0 持續 6 個月以上，自動降權。這是 regime change 的早期預警

**學理依據**：Ang & Bekaert (2002) "International Asset Allocation With Regime Switches" — 市場環境切換下的策略適應性

#### 3.7c 新策略方向 — 填補盲區

**問題診斷**：目前 22 個策略中，10 個技術面、3 個籌碼面、4 個基本面、3 個多因子、1 個產業、1 個事件。技術面過度集中，且缺少幾個在學術上被證實有效的經典因子。

- [ ] **動量因子策略（Cross-Sectional Momentum）**：Jegadeesh & Titman (1993) 經典動量 — 買入過去 12 個月報酬最高的前 20%，賣出後 20%（跳過最近 1 個月避免短期反轉）。這是全球股市最穩健的 Alpha 來源之一，目前系統竟然沒有
- [ ] **反轉因子策略（Short-Term Reversal）**：過去 1 週或 1 個月報酬最差的股票反彈。與動量互補，低相關性
- [ ] **品質因子策略（Quality Factor）**：ROE 穩定性 + 低財務槓桿 + 盈餘品質（應計比率）。Novy-Marx (2013) "The Other Side of Value" 證實品質因子與價值因子的組合效果卓越
- [ ] **低波動異常策略（Low Volatility Anomaly）**：Baker, Bradley & Wurgler (2011) — 低波動股票的風險調整後報酬優於高波動股。買入過去 60 日波動率最低的前 30%
- [ ] **盈餘修正策略（Earnings Revision）**：追蹤分析師盈餘預估的上修/下修方向。台灣可用月營收 YoY 的「加速度」（二階導數）作為代理變數

**學理依據**：Fama & French (2015) 五因子模型（Market, Size, Value, Profitability, Investment）— 目前系統覆蓋了 Market/Value，但缺少 Profitability 和 Investment 因子

#### 3.7d 現有策略深度優化

- [ ] **多因子模型重構**：目前的 `MultiFactorStrategy` 只用 RSI + MACD + 法人 + PER 四個因子，過於粗糙。應重構為：(1) 因子標準化（截面 Z-Score），(2) 因子正交化（去相關），(3) IC 加權組合，(4) 產業中性化（避免因子暴露被產業效應汙染）
- [ ] **法人跟單策略升級**：目前只看「連續 N 日買超」，但華爾街看的是「異常買超」— 買超金額偏離過去 60 日均值超過 2 個標準差。連續買超 3 日是表面現象，異常買超才是真正的資訊
- [ ] **價值投資策略加入安全邊際**：目前用絕對門檻（PER < 15），應改為相對門檻 — PER 低於同產業中位數的 1 個標準差，且處於自身歷史 PER 的底部 25%。這才是 Graham 的「安全邊際」精神
- [ ] **停損/停利機制系統化**：目前策略只有進出場訊號，沒有風控覆蓋。應在 `Backtester` 層面加入全局停損（-8%）、追蹤停利（從最高點回落 N%）、時間停損（持有超過 M 天強制出場）

#### 3.7e 選股報告可信度建設

**問題診斷**：每日選股報告是系統的最終產出，但目前缺乏「績效追蹤」— 你永遠不知道昨天推薦的股票後來表現如何。沒有追蹤的推薦等於沒有反饋的學習，系統無法進化。

- [x] **推薦績效追蹤表**：DB 表 `recommendation_history`（含版本指紋 git SHA + 策略 hash + JSONB 投票明細），每日自動回填 T+5/T+10/T+20 交易日績效，績效追蹤報告自動產出並 Email 推送（`scripts/performance_tracker.py`）
- [x] **推薦命中率儀表板**：`13_推薦追蹤.py` 四區塊（整體績效 + 策略拆分 + 排名 vs 績效 + 時間趨勢），資料層支援 SQLite/Supabase 環境變數切換
- [ ] **策略權重自適應**：基於推薦績效追蹤的結果，自動調整 `daily_stock_picker.py` 中各策略的投票權重（`STRATEGY_WEIGHTS`），表現差的策略自動降權
- [ ] **報告置信度標籤**：每支推薦股票標注「高信心 / 中信心 / 低信心」— 基於策略共識度（多少策略同時推薦）、訊號強度、歷史同類訊號的平均表現
